7651	### D-210 — Tighten the input boundary: class-uniform face uniqueness and no empty routing
7652	
7653	**Status.** ratified
7654	
7655	**Position.** Two input-boundary rules tighten, each completing a
7656	consequence [D-207][d-207] and [D-208][d-208] left implicit. The bundled rulings:
7657	
7658	- [§8.6][s8-6]'s face-name uniqueness invariant applies to the root component
7659	  whatever its class: a primitive root's face set is the union of its
7660	  `input_types` and `output_types` keys, and a key declared in both is the
7661	  same build error a duplicate face name is. Non-root primitives are
7662	  untouched.
7663	- An `input_connections` entry routes to at least one internal endpoint:
7664	  the empty tuple is a declaration error.
7665	
7666	**Spec.** [§8.2][s8-2], [§8.6][s8-6]
7667	
7668	**Rationale.** [D-208][d-208] made a primitive root's two contract declarations share
7669	the periphery's face namespace for the first time, and the prototype's
7670	conformance build showed what the gap costs: a primitive root declaring one
7671	key in both declarations places two cells at one address, the root-input
7672	placement silently overwriting the output port's. The repro authored
7673	`u = 5.0`, the stage published `10.0`, and the root input read back `10.0` —
7674	boundary-zero-ordered, and silent. An assembly root is protected by [§8.6][s8-6]'s
7675	uniqueness invariant; a primitive root had no analogue. The empty routing
7676	tuple is the same class of silence one level down: it contributes no
7677	consumer, so it is invisible to the total face graph [D-207][d-207] requires ([§9.2][s9-2]),
7678	and a condition addressing that face at a non-root level misdiagnoses as
7679	"declares no input face" — byte-identical to the diagnostic a bare typo
7680	earns. A face feeding nothing declares nothing.
7681	
7682	**Rejected.**
7683	- *Extending uniqueness to every primitive:* below the root a primitive's
7684	  input faces alias their producers' cells and place nothing, so there is no
7685	  addressable collision to forbid, and the rule would constrain leaf authors
7686	  for nothing.
7687	- *A sentinel entry in the face graph for a consumerless face:*
7688	  representation for a declaration with no meaning, and the misdiagnosis
7689	  survives in a new shape.
7690

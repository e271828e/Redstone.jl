2352	### D-078 — Treat input entries as face constraints checked by subtyping
2353	
2354	**Status.** ratified
2355	
2356	**Position.** Input entries are face constraints: wiring check `producer_face
2357	<: entry` at nominal faces — one uniform rule, exact equality the concrete
2358	degenerate.
2359	
2360	**Spec.** [§4.4][s4-4], [§8.2][s8-2], [§9.1][s9-1]
2361	
2362	**Rationale.** Abstract entries = structural substitutability ([§4.4][s4-4] field
2363	handles), never needed for eltype genericity (an eltype-generic producer's
2364	nominal face is concrete by construction); root-slot carve-out — only a tight
2365	(concrete) bound determines a producerless cell's type, abstract-at-root a
2366	build error; under fan-out the slot type is the unique concrete declaration
2367	among consumers, abstract co-consumers checked against it; doctrine:
2368	declarations record choices, obligations are checked.
2369	
2370	**Rejected.**
2371	- *Exact-equality-only status quo:* welds [§4.4][s4-4] consumers to one concrete
2372	  producer type, or leaks wiring facts into component type parameters —
2373	  `Strut{H}` cascading through every owning assembly.
2374	- *Symmetric `T` as genericity envelope:* a per-leaf marking that is a constant
2375	  function across components — zero information, wrong granularity,
2376	  false-affordance pins; the predictive reading remains impossible per [D-054][d-054].
2377	- *Phantom root producer with `output_types`-style slot declarations:*
2378	  re-enumerates what exports already are — [D-043][d-043]'s `add_input!` reborn;
2379	  two-artifact drift; root-ness is deployment, not type; its pin bit is policy
2380	  wearing a description's syntax — pinned ≡ unseeded to every derivative.

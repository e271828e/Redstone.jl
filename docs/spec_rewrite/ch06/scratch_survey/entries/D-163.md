5669	### D-163 — Ban `==` for separately-compiled float comparisons
5670	
5671	**Status.** ratified
5672	
5673	**Position.** **Float outputs are compared leaf-wise with a tolerance, never
5674	`==`, wherever the two sides are separately compiled** — the executor contracts
5675	`a*b - c*d` into an FMA where a differently-compiled reference (a type-unstable
5676	evaluator, a hand-rolled per-component check, today's FlightCore path in `migration_outline.md`'s
5677	comparison) does not, and along a dependency chain the last-ulp difference
5678	accumulates.
5679	
5680	**Spec.** [§6.2][s6-2], [§7.5][s7-5]
5681	
5682	**Rationale.** Increment-1 observation promoted to doctrine; measured in
5683	`prototypes/cellstore_bench`'s `check.jl`, same class as the main line's
5684	3945596. Two consequences past test hygiene: [§9.7][s9-7]'s chunk size remains a
5685	genuine implementation freedom only while no test asserts bit-exactness across
5686	chunk sizes, and the FlightCore value comparison in `migration_outline.md` is a tolerance comparison by
5687	construction, not by concession. Determinism is untouched — within one build
5688	the schedule is fixed and [§6.2][s6-2] made every sum an ordered junction entry, so a
5689	run reproduces itself bit-for-bit.
5690	
5691	**Rejected.**
5692	- *Bit-exact assertions under a `muladd`-free or pinned-math build:* buys a
5693	  brittle equality by giving up the codegen [§7.5][s7-5]'s invariant depends on.
5694	- *Per-test ad-hoc tolerances:* precisely what stating it once as doctrine
5695	  prevents.

7747	### D-212 — Refuse the transparent bare key that shadows a sibling container field
7748	
7749	**Status.** ratified
7750	
7751	**Position.** Completing [D-211][d-211]'s collision family (annotating [D-211][d-211]): a
7752	name-transparent element's bare key equal to the name of a sibling container
7753	field that contributes children is a build error naming both parties, although
7754	no child bears that name — the key shadows the container's `"field/key"`
7755	segment grammar ([§6.1][s6-1]), leaving its elements unreachable behind a one-level
7756	diagnostic that blames the wrong child. An empty field reserves nothing: it
7757	reaches no children, its value cannot be told from empty inert parameter data,
7758	and the judgment is per-instantiation, like every wiring judgment.
7759	
7760	**Spec.** [§8.5][s8-5]
7761	
7762	**Rationale.** Surfaced by increment 20's cold review: [D-211][d-211]'s collision check
7763	compares the names children actually bear, and the shadow collides with none of
7764	them — the build succeeded while the shadowed container's elements stayed in
7765	the flat list yet became unreachable in wiring resolution, the one-level
7766	rejection reporting them as reaching past the bare child and advising a route
7767	through that child's faces. The empty-field exemption was settled the hard
7768	way: uniform reservation was built first and immediately displaced the
7769	instantiation-dependence onto inert fields, where the refusal is a false
7770	positive — an empty `Tuple`/`NamedTuple` is an empty container and empty inert
7771	parameter data at once, the value cannot tell them apart, and [§8.5][s8-5] keeps empty
7772	containers legal precisely so parametric code needs no special case.
7773	Per-instantiation legality is the norm, not a defect: every wire is validated
7774	against the instance too.
7775	
7776	**Rejected.**
7777	- *Leaving it to [D-211][d-211]'s duplicate-name check:* it compares the names children
7778	  bear, and the shadow collides with none — a grammar collision, not a name
7779	  collision.
7780	- *Reserving every empty `Tuple`/`NamedTuple` field's name (uniform refusal):*
7781	  built and reverted within the increment — it refuses a bare key over inert
7782	  data where no shadow exists (`Group`'s own empty `wires` beside a child
7783	  named `wires`), trading a true per-instantiation refusal for a false one.
7784	- *A better diagnostic only, admitting the shadow:* the ambiguity is real —
7785	  one grammar answering for two children — and the same instinct as [§8.6][s8-6]'s
7786	  face-name uniqueness invariant applies: ambiguity is refused, not
7787	  documented.

4840	### D-143 — Add a `Constant` source block for zero-contributor aggregates
4841	
4842	**Status.** ratified
4843	
4844	**Position.** The component library gains a source block, `Constant{V}`, and
4845	[§6.2][s6-2] gains the spelling for a zero-contributor aggregate. Contract: an ordinary
4846	component, no framework privileges, no inputs, no state,
4847	`output_types(::Constant{V}) = (out = V,)` with the value type from the type
4848	parameter and the value itself held by the instance, and a stage-1 body
4849	returning it; `Constant(Wrench()) → dynamics/wr_ext` is the whole remedy. Two
4850	clarifications ride with it: (i) this is not [§6.1][s6-1]'s banned default in component
4851	clothing but its opposite — the banned default is silent and consumer-declared,
4852	the `Constant` is loud and assembly-declared, the author writing both the child
4853	and the wire, both inspectable structure; (ii) the value is instance data, not
4854	an overridable default — like junction arity it is baked into the instance, and
4855	a configuration wanting an externally settable source uses a root slot ([§11.3][s11-3]),
4856	the boundary that keeps the block from drifting into a back-door input default.
4857	Tier: stateless continuous, so [§13.7][s13-7]'s existing tier-transparency argument (a
4858	stateless `h_xu` recomputes every sweep, so fed ZOH-held signals its output
4859	changes only at ticks) already covers discrete consumers — no discrete variant.
4860	
4861	**Spec.** [§6.1][s6-1], [§6.2][s6-2], [§11.3][s11-3], [§13.7][s13-7], [Appendix D][sD]
4862	
4863	**Rationale.** [D-037][d-037]'s retirement and [§6.1][s6-1]'s ban are preserved, not reopened,
4864	by this decision. The gap the dry run walked: `Vehicle{NoVehicleSystems}`
4865	(`aircraftbase.jl:27-35`) contributes zero to both external wrench and internal
4866	angular momentum while `VehicleDynamics` requires both inputs unconditionally,
4867	[§6.1][s6-1] forbids unconnected inputs and silent defaults, a zero-arity `SumJunction`
4868	would need the identity element [D-037][d-037] retired on purpose, and the library had
4869	no block that produces without consuming — so the bare-propagation
4870	configuration (`test_dynamics.jl`, any kinematics-only world) had no legal
4871	spelling at all. The argument is visible structure: the zero total becomes a
4872	declared wire and an observable port — the configuration stating "external
4873	wrench ≡ 0" out loud — instead of FlightCore's silent identity methods, whose
4874	zero-edit convenience is the hazard ([D-037][d-037]'s own words). It also subsumes the
4875	rig stub: [D-120][d-120]'s concrete `SampleTerrainField` provider wired to an abstract
4876	`terrain` face is typically just a `Constant` holding the test handle — the
4877	block's first shipped instance — while bespoke stubs stay ordinary components
4878	wherever the double must compute something. Admission honors [§13.7][s13-7]'s strictly
4879	from demonstrated need charter: the dry run demonstrated the need twice, at the
4880	zero-contributor totals and at the rig. [Appendix D][sD] gains a constant source
4881	entry.
4882	
4883	**Rejected.**
4884	- *A zero-arity summing junction with an identity element:* [D-037][d-037]'s retirement
4885	  stands — reintroducing identity machinery for the degenerate case buys
4886	  nothing the source block does not, and reopens the canonical-fold and
4887	  identity-element rules retired wholesale.
4888	- *Consumer-side optional inputs or unwired defaults:* [§6.1][s6-1]'s ban — the silence
4889	  is the hazard, the same property [D-037][d-037] rejected in the tree walk.
4890	- *A configuration-aware `VehicleDynamics` branching on whether contributors
4891	  exist:* pushes configuration structure into component code, where no diagram,
4892	  printer or diagnostic can see it, and makes a component's contract depend on
4893	  the assembly it sits in.
4894	- *Bespoke per-configuration stub components as the general answer:* legal, and
4895	  still the answer for computing stubs, but boilerplate at every
4896	  zero-contributor site — `Constant` subsumes the constant-valued case, which
4897	  is all of them.

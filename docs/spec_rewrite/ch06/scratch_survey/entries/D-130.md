3982	### D-130 — Scope `resolve`'s generic-boundary duty by client (wiring/service/inspection)
3983	
3984	**Status.** ratified
3985	
3986	**Position.** `resolve`/`resolve_terminal`'s generic-boundary duty is
3987	client-scoped — [D-083][d-083]'s line carried into resolution: *wiring* (connection
3988	declarations, Stratum A) strict as stated; *service* (condition entries, trim
3989	`reads`, taps) strict at the authoring or mount level (the locality law is
3990	authoring-level, [§14.2][s14-2] — absolute paths are a compiled derivative — and the
3991	mount prefix is checked by the mount itself, [§14.9][s14-9]'s contract validation);
3992	*inspection* (device read bindings, GUI panels, snapshot/log inspection) the
3993	instance walk — a generic seam is no error for a client that never claimed
3994	substitutability, drift still loud at attach (`ReadBindingUnresolved`); which
3995	of the three a client falls under is internal, never user-facing API
3996	([§14.4][s14-4]'s `apply!` precedent). This amends [D-061][d-061].
3997	
3998	**Spec.** [§13.3][s13-3], [§14.2][s14-2], [§14.4][s14-4], [§14.9][s14-9]
3999	
4000	**Rationale.** Not [D-061][d-061]'s rejected instance-only walk: the declared-type walk
4001	stays the primitive's semantics and stays enforcing where promises depend on
4002	it.
4003	
4004	**Rejected.**
4005	- *A single unconditional strict rule:* as written it made [D-083][d-083]'s blessed
4006	  inspection reads unreachable in any real tree — the shipped XPlane
4007	  binding, GUI panels and the log all traverse generic seams — and broke
4008	  [§14.9][s14-9]'s mounting on compiled absolute paths.
4009	- *A public client parameter on `resolve`:* client policy is
4010	  framework-internal; [§14.4][s14-4] precedent.
4011	- *Permissive resolution for service clients at the compiled path:* erases
4012	  the locality law exactly where substitution safety pays — [D-125][d-125]'s rejected
4013	  deep-path reads.

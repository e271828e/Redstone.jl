1264	### D-040 — Slash-string paths as the canonical path form
1265	
1266	**Status.** ratified
1267	
1268	**Position.** Slash-string paths, relative to the declaring assembly, one
1269	canonical form shared by declarations, diagnostics, devices and logs.
1270	
1271	**Spec.** [§8.6][s8-6]
1272	
1273	**Rationale.** Recorded only through the rejections below.
1274	
1275	**Rejected.**
1276	- *Instance navigation:* `===`-identical symmetric siblings make
1277	  path-from-instance unrecoverable — proxies remain sugar.
1278	- *Symbol tuples:* structure without readability.
1279	- *Dotted paths:* false Julia-property affordance — the last segment is a port,
1280	  not a field.

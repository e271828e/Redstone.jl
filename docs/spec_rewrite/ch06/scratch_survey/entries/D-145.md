4957	### D-145 — Deduplicate pass-through `except` lists with a shared feed-list idiom
4958	
4959	**Status.** ratified
4960	
4961	**Position.** Pass-through exports duplicate the wiring list at every generic
4962	seam — every level of the real tree is a generic seam, so each pilot- and
4963	environment-facing input surfaces through four `exports` declarations
4964	(`Systems` → `Vehicle` → `Aircraft` → `SimpleWorld`), and because `passthrough`
4965	is inputs-only and re-exporting a fed face is a two-producers error, each call
4966	carries an `except` tuple restating by name the wire list in the same
4967	assembly's `connections`. No new vocabulary and no framework change: [§8.8][s8-8]
4968	gains a worked shared-feed-list idiom beside the two-entry-`except` `World`
4969	example — the author writes one constant, the feed list mapping the actuator
4970	child's output faces to destination child faces, and both declarations compute
4971	their share of it (`connections` maps the list into wires; each `passthrough`
4972	call takes its `except` set from a small `fed_faces(feeds, child)` projection),
4973	[§8.5][s8-5]'s blessing of declaration bodies as ordinary code doing the work.
4974	
4975	**Spec.** [§8.4][s8-4], [§8.5][s8-5], [§8.8][s8-8], [§14.6][s14-6]
4976	
4977	**Rationale.** [D-043][d-043] is reaffirmed, not reopened, by this finding, which closes
4978	the round-4 dry-run report. The drift is caught loudly — the design working —
4979	but the duplication is [§8.1][s8-1]'s and [D-039][d-039]'s "structure kept in two artifacts"
4980	(~10 names at `Systems`, everything `c172.jl:697-713`'s `assign!` writes).
4981	Doctrine recorded with it: adding a channel is one edit (the pair
4982	simultaneously creates the wire and removes the face from the export surface),
4983	the two declarations cannot drift because neither holds the shared names — the
4984	drift class is removed, not merely detected — and every existing error stays
4985	loud (a misspelled destination is an unknown-face error with the child's face
4986	list in hand, whether the wire or the `except` entry meets it first); one
4987	honest asymmetry: a pair omitted from the list is not an error but a legible
4988	structural change — the face joins the export surface, ultimately a root slot
4989	for conditions to cover ([§14.6][s14-6]) — what the idiom preserves and the rejected
4990	helper surrenders is that the feed statement exists to be reviewed, an omission
4991	being legible in one authored artifact rather than defined away as the
4992	complement of the wire list. The gap being closed was pedagogical, not
4993	semantic: the section's only example hand-wrote a two-entry `except`, reading
4994	as though the duplication stays small, when at C172X scale it is four
4995	hand-synchronized name lists.
4996	
4997	Annotation (2026-10-02): "structure kept in two artifacts" is [D-039][d-039]'s alone,
4998	and [§8.8][s8-8] states it; [§8.1][s8-1] holds no such phrase.
4999	
5000	**Rejected.**
5001	- *A framework helper deriving `except` from `connections`* (`except = fed(s,
5002	  "aero")` reading the assembly's own wire list): auto-bubbling on [D-043][d-043]'s
5003	  exact ground — the author's explicit statement of which faces are fed
5004	  disappears, so a forgotten wire stops being a build-time unconnected-input
5005	  error and becomes a silent promotion of that face to a live root slot, caught
5006	  at best later as an `UninitializedSlots` deployment error of misleading
5007	  shape, at worst not at all once a GUI or condition writes it — [§8.4][s8-4]'s
5008	  walkthrough 2 inverted; the single source must be authored data, never
5009	  inferred structure.
5010	- *Wildcard-export vocabulary:* [D-043][d-043] stands — ordinary code suffices, and this
5011	  row is the demonstration that was missing.
5012	- *Doing nothing:* the status quo prices the idiom's absence at four
5013	  hand-synchronized lists per generic seam chain, a measured migration-day cost
5014	  rather than a hypothetical one.

7602	### D-208 — Root inputs are the root component's input faces, whatever its class
7603	
7604	**Status.** ratified
7605	
7606	**Position.** The build accepts any component as root, and the model's root
7607	inputs are the root's input faces uniformly. The bundled rulings:
7608	
7609	- For an assembly they are its `input_connections` keys, each traced
7610	  through the total face chain ([D-207][d-207]) to leaf input entries; for a
7611	  primitive, its `input_types` keys directly — [D-172][d-172]'s kind-blind faces
7612	  applied at the root.
7613	- Types keep their derivation (the ultimate consuming entry at the
7614	  activation scalar, [§8.2][s8-2]'s tight-bound rule; a primitive root's face is its
7615	  own consuming entry), and [§8.2][s8-2]'s primitive-root refusal is retired.
7616	- Abstract-at-root is unchanged: a primitive with an abstract input entry
7617	  still cannot be built bare, and the component test rig ([§13.7][s13-7]) keeps its
7618	  stubbing role, losing only its gate status.
7619	
7620	**Spec.** [§8.2][s8-2], [§8.6][s8-6], [§9.1][s9-1], [§9.3][s9-3], [§11.3][s11-3], [§13.7][s13-7]
7621	
7622	**Rationale.** The refusal existed because no rule made a primitive root's
7623	unfed inputs root inputs; the uniform doctrine supplies one with no new
7624	vocabulary, and the one-child wrapper it forced on leaf exercise added a
7625	level of ceremony without adding information.
7626	
7627	**Rejected.**
7628	- *Keeping the assembly-only root:* with the doctrine uniform, the
7629	  remaining justification was the rig idiom, which survives on its own
7630	  merits.

12596	### D-299 — Rate scopes by type, the feed-list doctrine and the helper pair
12597	
12598	**Status.** ratified
12599	
12600	**Position.** Five rulings that [§8.7][s8-7] and [§8.8][s8-8] state are fixed here.
12601	
12602	- A `sample_times` declaration belongs to the assembly type, not to the
12603	  child instance, because the ratio it declares is type-intrinsic, never a
12604	  per-instance value.
12605	- Adding a channel to a feed list is one edit: the new pair creates the wire
12606	  and removes the face from the input face surface at once. The two
12607	  declarations cannot drift, because neither holds the shared names, so the
12608	  drift class is removed rather than detected. The single source must be
12609	  authored data, never inferred structure.
12610	- The passthrough helpers come in a pair, `input_passthrough` and
12611	  `output_passthrough`, and the name carries the direction. After the
12612	  boundary declarations split by direction, a single call cannot emit
12613	  entries into two declarations.
12614	- `output_passthrough`'s consumer is one-level routing. Every level
12615	  re-exports the outputs it surfaces, so the output side needs the computed
12616	  spelling the input side already has.
12617	- At a root input, scalar faces make partial scripting compose. A bundled
12618	  face there collides with [§4.3][s4-3]'s write-side granularity and forfeits
12619	  partial scripting.
12620	
12621	**Spec.** [§8.7][s8-7], [§8.8][s8-8]
12622	
12623	**Rationale.** Each bullet restates what an existing entry recorded outside
12624	its Position. The type-intrinsic ratio was recorded in [D-042][d-042]'s Rejected
12625	list. The one-edit feed list and the removed drift class were recorded in
12626	[D-145][d-145]'s Rationale, and authored data over inferred structure in its Rejected
12627	list. The helper pair was recorded in [D-171][d-171]'s Rationale, and one-level
12628	routing as `output_passthrough`'s consumer in [D-209][d-209]'s. Scalar faces at a root
12629	input were recorded in [D-207][d-207]'s Rejected list.

12631	**Rejected.** None beyond the source entries' lists.

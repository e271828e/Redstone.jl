D-406: **Position.** Attach resolves a binding's `reads` through the read-selector family's one collecting resolver, the resolver trim and linearization already use ([§11.2][s11-2], [§13.1][s13-1], [§14.4][s14-4]). The bundled rulings: - The resolver takes the source it resolves for, live stores or a signal table. Under a table source a store selector is refused as `:store_selector`, with the remedy named. The source rule is the resolver's, not a client's. - The refusals the resolver raises are one kind, `ReadResolution`, collected and surfaced at every site. `TapResolution` keeps [§14.10][s14-10]'s five tap-set reasons alone. `ReadBindingUnresolved` retires. - A binding's path selector names a primitive's own port, as every reader's does, and a face an assembly exports is read with `get_face`. The admission of an assembly's output face, or of a root input, under `get_output(path, name)` retires, having never been ruled. - A binding's read set resolves at the root, with no mount. Whether it may carry an `at` chain is left open until a binding needs an inner assembly's face ([D-199][d-199]). - A read refusal at attach carries the read's label and not the device. The `attach!` call names the device and the binding (amends [D-216][d-216]). 
D-407: **Position.** Post-run extraction from the log is `series(sim, read_set)`. It resolves a read set against the build for a table source, through the one resolver every reader shares ([D-406][d-406]), gathers each labeled entry over the retained snapshots into one typed column, and returns the columns labeled as the set labels them, beside the snapshots' `t`, frame and boundary ordinals ([§11.2][s11-2], [Appendix B][sB]). The bundled rulings: - The read set is the `Reads` value trim's `reads` builds, so `at` mounts it and every table selector with its leaf address reads the log; a store selector is refused under the source rule. - A column is a plain vector of the entry's leaf type. No wrapper stands between a column and the plotting or analysis package that consumes it. - Resolution runs once per call. Compilation specializes on each entry's leaf type and chain and never on the label set. - The names `series` and `Series` are provisional until the export audit ([D-226][d-226]).

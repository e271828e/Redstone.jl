1421	### D-045 — Periphery input semantics: derived liveness, conditioning, mappings, edge logic
1422	
1423	**Status.** ratified
1424	
1425	**Position.** Periphery input semantics are settled on five points — liveness,
1426	conditioning, mappings, edge logic and pokeability:
1427	
1428	- GUI liveness is fully derived: transitive root-slot resolution ∧ slot
1429	  unclaimed.
1430	- Faces carry writer-independent post-conditioning semantics, the GUI-parity
1431	  test.
1432	- Mappings are declarative binding data with per-axis conditioning params,
1433	  living on the device task.
1434	- Edge logic is staged counters plus model-state accumulators.
1435	- Unexported ports are unpokeable.
1436	
1437	**Spec.** [§4.3][s4-3], [§11.7][s11-7]
1438	
1439	**Rationale.** Recorded only through the rejections below.
1440	
1441	**Rejected.**
1442	- *Per-port "GUI-controlled" markings:* the export chain is the marking, owned
1443	  by the right author.
1444	- *Nominally-connected + GUI override channel:* second write path; breaks frame
1445	  purity and trace; done right it collapses into root slots.
1446	- *Conditioning in-model:* fails GUI-parity — sliders and scripts would be
1447	  deadzoned.
1448	- *Shaping as per-device mapping code:* aircraft semantics duplicated per
1449	  device — today's demonstrated smell.
1450	- *Joystick-as-component and root-level `PilotInterface`* (`flight_case_studies.md`): replay
1451	  same-build, single audit point, no natural home in `World`. Annotation (from
1452	  the C172X case study's inline treatment, migrated): devices-as-components also duplicates
1453	  [§12.4][s12-4]'s device lifecycle in component vocabulary and costs the drain its
1454	  standing as the single audit point for external data, while the GUI stays
1455	  irreducibly a staging device so inbound uniformity is unreachable either way
1456	  — and the rejection rests on these invariants, not on [§12.5][s12-5]'s clock
1457	  criterion, the scheme being internally consistent in an interactive paced
1458	  world.
1459	- **Bundled command faces** (`pilot_inputs` as one struct port): kills
1460	  per-field claiming, liveness and trace tag — the port is the
1461	  periphery's atomic unit on the write side too, [§4.3][s4-3] — and the routing
1462	  convenience it bought under argument threading is the namespace prefix plus
1463	  `input_passthrough` here.

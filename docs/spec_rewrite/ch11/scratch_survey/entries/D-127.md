3963	### D-127 — Add a deployment block to the trace header for replay validation
3964	
3965	**Status.** ratified
3966	
3967	**Position.** The trace header gains a **deployment block** — `t₀`, `Δt_base`,
3968	`h`, `n`, the algorithm identifier and the effective `t_end`/`stop_on` pair,
3969	captured with the stores. [§12.7][s12-7]'s up-front pass treats it in two ways:
3970	`Δt_base`/`h`/`n`/algorithm compared against the target's deployment binding
3971	(widened to six by [D-133][d-133]: `localization_tol` and `event_budget` join both the
3972	block and the comparison), mismatch = `ReplayHeaderMismatch` with a new
3973	deployment-parameter discriminator — structural, never a what-if, since a
3974	deployment change moves the times at which frame-ordinal batches apply
3975	(different inputs, not a modified model); `t₀` applied rather than compared
3976	(replay stands in the `init!` position and owns the anchor — no new `replay!`
3977	argument); the termination pair recorded but never constraining (overrides bind
3978	at replay as at `run!`, [D-091][d-091]).
3979	
3980	**Spec.** [§11.5][s11-5], [§12.7][s12-7], [§13.5][s13-5], [Appendix B][sB], [Appendix C][sC]
3981	
3982	**Rationale.** Defined as the artifact "run metadata" already named three times
3983	without a home ([§13.5][s13-5] ×2, [Appendix B][sB]; [D-091][d-091]'s obligation, now discharged).
3984	
3985	**Rejected.**
3986	- *Validating the whole block uniformly:* freezes `t_end`/`stop_on`, which
3987	  [§12.7][s12-7] explicitly leaves overridable, and a recorded `stop_on` termination
3988	  reproduces itself anyway.
3989	- *An overridable deployment check to allow what-if-with-different-`h`:* not a
3990	  what-if under [§12.7][s12-7]'s own definition — what-if replay promises the recorded
3991	  inputs, and ordinal keying re-times them under a changed grid.
3992	- *A separate `ReplayDeploymentMismatch` kind:* one validation pass, one
3993	  carrier — the payload discriminator mirrors the store/slot split already
3994	  there.

4051	### D-130 — Scope `resolve`'s generic-boundary duty by client (wiring/service/inspection)
4052	
4053	**Status.** ratified
4054	
4055	**Position.** `resolve`/`resolve_terminal`'s generic-boundary duty is
4056	client-scoped — [D-083][d-083]'s line carried into resolution: *wiring* (connection
4057	declarations, Stratum A) strict as stated; *service* (condition entries, trim
4058	`reads`, taps) strict at the authoring or mount level (the locality law is
4059	authoring-level, [§14.2][s14-2] — absolute paths are a compiled derivative — and the
4060	mount prefix is checked by the mount itself, [§14.9][s14-9]'s contract validation);
4061	*inspection* (device read bindings, GUI panels, snapshot/log inspection) the
4062	instance walk — a generic seam is no error for a client that never claimed
4063	substitutability, drift still loud at attach (`ReadBindingUnresolved`); which
4064	of the three a client falls under is internal, never user-facing API
4065	([§14.4][s14-4]'s `apply!` precedent). This amends [D-061][d-061].
4066	
4067	**Spec.** [§13.3][s13-3], [§14.2][s14-2], [§14.4][s14-4], [§14.9][s14-9]
4068	
4069	**Rationale.** Not [D-061][d-061]'s rejected instance-only walk: the declared-type walk
4070	stays the primitive's semantics and stays enforcing where promises depend on
4071	it.
4072	
4073	**Rejected.**
4074	- *A single unconditional strict rule:* as written it made [D-083][d-083]'s blessed
4075	  inspection reads unreachable in any real tree — the shipped XPlane
4076	  binding, GUI panels and the log all traverse generic seams — and broke
4077	  [§14.9][s14-9]'s mounting on compiled absolute paths.
4078	- *A public client parameter on `resolve`:* client policy is
4079	  framework-internal; [§14.4][s14-4] precedent.
4080	- *Permissive resolution for service clients at the compiled path:* erases
4081	  the locality law exactly where substitution safety pays — [D-125][d-125]'s rejected
4082	  deep-path reads.

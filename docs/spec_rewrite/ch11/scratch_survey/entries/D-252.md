9709	### D-252 — Remove auto-publishing: two port classes, exposed state returned by stage 1
9710	
9711	**Status.** ratified
9712	
9713	**Position.** A declared output is produced by stage 1 or by stage 2, and by
9714	nothing else. A component exposes a state or mode field by returning it from
9715	`output_state`. A declared output that no stage produces is
9716	`DeclaredNotProduced`, everywhere and at every tier. `ProducedByTwoStages`
9717	carries the component path and the port name; the two stages are the kind's
9718	own, so the producer column goes with the third class. Supersedes [D-016][d-016]'s
9719	publication rule, [D-152][d-152]'s successor in [D-154][d-154]'s sequence, and [D-169][d-169].
9720	
9721	**Spec.** [§5.2][s5-2], [§5.3][s5-3], [§7.1][s7-1], [§8.3][s8-3], [§9.1][s9-1],
9722	[§9.3][s9-3], [§10.6][s10-6], [§11.2][s11-2], [§13.2][s13-2], [Appendix B][sB],
9723	[Appendix C][sC], [Appendix D][sD]
9724	
9725	**Rationale.** Auto-publishing was a third port class the framework wrote.
9726	It cost more than the line it saved. Stage 1's hand-down had to exclude the
9727	published names ([D-169][d-169]), the classifier probed by name and type and silently
9728	un-published a name held at another type, the executor grew a
9729	`PublishEntry` beside the stage entries, the published set threaded through
9730	every stratum and into `compile`'s key slicing, and a `ConformanceFailure`
9731	arm existed only to refuse a `Float64`-pinned declaration of a walking field
9732	at the `Dual` activation. Each piece was correct and each was there for one
9733	convenience: not writing `output_state(c, (; x)) = (; q = x.q)`. The
9734	2026-09-18 probe over the suite found nine of seventy-eight fixture
9735	components relying on publication, six of them written to test it. The
9736	remaining refusal already exists: `DeclaredNotProduced` names the declared
9737	port, the stage products and the store fields, and its remedy becomes
9738	"return it from `output_state`". With one writer per port the port model is
9739	homogeneous, the `Dataflow` artifact ([D-253][d-253]) classifies by return alone, and
9740	the trace and status surfaces stop distinguishing a framework write from a
9741	stage write.
9742	
9743	**Rejected.**
9744	- *Keeping publication as it stood:* the machinery above, for one line per
9745	  exposed field.
9746	- *Opt-in publication sugar (a declaration listing fields to expose):* a
9747	  second way to write `output_state`'s return, with the same classification
9748	  seam.
9749	- *A dev-mode flag publishing every state field ([§11.7][s11-7]'s note):* still
9750	  possible as a debugging aid, but it would be a reader over the stores, not
9751	  a port class; it is recorded, not built.
9752	- *Refusing only at the root:* an unproduced port inside an assembly is the
9753	  same silent zero, one level down.

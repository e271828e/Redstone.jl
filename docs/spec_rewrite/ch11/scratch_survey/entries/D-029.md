987	### D-029 — Input trace on by default
988	
989	**Status.** ratified
990	
991	**Position.** Input trace on by default, cleared at `init!`, plain kill switch.
992	
993	**Spec.** [§11.2][s11-2], [§11.5][s11-5], [Appendix B][sB]
994	
995	**Rationale.** Recorded only through the rejections below.
996	
997	**Rejected.**
998	- *Opt-in:* the trace is primary data — the log is recomputable from it, never
999	  the reverse; the session you need replayed is the one you didn't plan to
1000	  record.
1001	- *Tying trace to the log switch:* conflates primary and derived recording.
1002	- *Rolling window/sampling:* complexity without a customer.

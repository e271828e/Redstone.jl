7964	### D-215 — Extend Appendix C with the kinds the prototype raised
7965	
7966	**Status.** ratified
7967	
7968	**Position.** Seven kinds join [Appendix C][sC]'s closed set, and two vocabularies widen.
7969	
7970	- Build, collected: `ChildNameCollision` (a bare container key against the
7971	  `sample_times` sugar or a sibling field, or two children with one name),
7972	  `TransparentContainerUnknown`, `TierUnreadable` (the tier twin of
7973	  `ClassUnreadable`), `IllegalPortType` (the port twin of `IllegalStateLeaf`).
7974	- Service, fail-fast: `ArgumentInvalid` (the twin of `DeploymentInvalid` for
7975	  arguments that are not deployment parameters — `step!`'s, `trim!`'s,
7976	  `TableBinding`'s, a period constructor's), `ReadSetMisuse` (the read
7977	  side's twin of `ConditionNodeMisuse`), `NotAttached` (`detach!`'s mirror
7978	  of `AlreadyAttached`).
7979	- `UnknownPort`'s wire end admits `connection`, an interface-connection entry's
7980	  internal side ([D-210][d-210]); `EventHalfMissing`'s reason admits an entry that is
7981	  not an `Event`.
7982	- Internal invariant checks are not diagnostics: they raise a distinct
7983	  `InternalInvariant` exception outside the kind set.
7984	
7985	**Spec.** [§8.2][s8-2], [§8.5][s8-5], [§13.2][s13-2], [Appendix C][sC]
7986	
7987	**Rationale.** Surfaced by the site inventory for the prototype increment
7988	retiring its string stand-in: 31 of its 144 refusal sites matched no [Appendix C][sC]
7989	row, and [Appendix C][sC] makes adding a kind a decision-log entry. Most are
7990	behaviors the log already rules without naming the kind — [D-210][d-210]'s empty route,
7991	[D-211][d-211]'s and [D-212][d-212]'s child-name collisions — or twins of existing kinds on
7992	another axis: class versus tier, state leaf versus port type, condition node
7993	versus read selector, attach versus detach. The argument checks share one kind
7994	because they share one payload shape — the call, the argument, the value, the
7995	constraint — exactly as the deployment parameters share `DeploymentInvalid`.
7996	An internal invariant has no fix for the user to be told; a kind for it would
7997	put an unreachable check into the acceptance-test contract.
7998	
7999	**Rejected.**
8000	- *A kind per argument check (`StepArgumentInvalid`, `TableBindingInvalid`,
8001	  …):* the row count grows with the API surface while the payload shape stays
8002	  identical.
8003	- *Folding `TierUnreadable` into `ClassUnreadable`:* a different axis —
8004	  primitive-versus-assembly against continuous-versus-discrete — with a
8005	  different list-in-hand.
8006	- *Internal invariants as a kind:* a diagnostic states the user's fix; an
8007	  invariant has none, and its row would be an untestable contract.
8008	- *Leaving the unmapped sites as message-only errors:* the string stand-in
8009	  reintroduced inside the increment retiring it.

828	### D-022 — Periphery architecture: no shared mutable model
829	
830	**Status.** ratified
831	
832	**Position.** Periphery architecture: no shared mutable model — staged inputs
833	drained at frame top + immutable snapshot published per boundary; every handoff
834	one atomic reference op, GC as reclamation; no user code or unbounded work in
835	framework critical sections; control on a separate atomic surface (staging
836	cannot un-pause a drainless loop); interactive = batch + devices.
837	
838	**Spec.** [§2][s2], [§11.1][s11-1]
839	
840	**Rationale.** Recorded only through the rejections below.
841	
842	**Rejected.**
843	- *Transplanted `io_lock`:* loop budget hostage to arbitrary code under the
844	  lock; input timing scheduler-determined and unrecorded — replay undefinable
845	  in principle; protects a live-mutation idiom the immutable table removed.
846	- *Full message-passing periphery:* per-device typed channels — same design
847	  with heavier ceremony.

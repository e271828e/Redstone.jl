5451	### D-153 — Add re-arm tracking to complete the once-per-event rule
5452	
5453	**Status.** ratified
5454	
5455	**Position.** **The event phase's per-event loop state is named and normative —
5456	the prior ([D-082][d-082]), a `fired` flag (the once-per-event rule's register), and a
5457	within-boundary `re-arm` flag**, set when a round observes the event fired and
5458	its guard not-holding; `EventDeferred` emits (at most once per event per
5459	boundary) when a round observes fired ∧ re-armed ∧ holding — the genuine
5460	intra-boundary falling-then-rising edge, never the blessed sticky case
5461	(fired-and-keeps-holding warns nothing).
5462	
5463	**Spec.** [§10.6][s10-6], [§11.7][s11-7], [§11.8][s11-8], [Appendix C][sC]
5464	
5465	**Rationale.** A round-5 kernel dry-run finding (finding 9), completing [D-082][d-082]'s
5466	prior rule. **A deferred event's quiescence prior is recorded not-holding**
5467	(the intra-boundary re-arm edge survives the boundary), so it genuinely fires
5468	at the next boundary — under the bare prior rule the quiescent holding sample
5469	would swallow the edge and the promised "waits one step" would never resolve.
5470	All three registers are detection bookkeeping in loop state — not `z`, not
5471	captured, reset by warm restart ([D-082][d-082]'s doctrine extended); cost budgeted
5472	explicitly: two `Bool`s per event beyond the prior.
5473	
5474	Annotation (2026-10-02): amended by [D-181][d-181] and [D-292][d-292]. The `fired` and
5475	`re-arm` flags and `EventDeferred` are retired; the registers are the prior,
5476	the last-observed sample and the firing count. That they are named and normative
5477	stands.
5478	
5479	**Rejected.**
5480	- *The warn-on-holding-after-fired rule:* the only one implementable from the
5481	  spec's stated registers — false-positives on every sticky flag, a
5482	  per-boundary warning stream consuming the 16-entry ring [§11.8][s11-8] budgets for real
5483	  diagnostics — the anti-diagnostic pattern [§11.7][s11-7] names.
5484	- *Dropping `EventDeferred`:* silent deferral, against the
5485	  flag-the-granularity-cost doctrine the once-per-event rule was adopted with.
5486	- *Prior = final quiescent sample unconditionally:* [D-082][d-082] as written — swallows
5487	  the re-arm edge, so the deferral never resolves and "waits one step" is
5488	  false.

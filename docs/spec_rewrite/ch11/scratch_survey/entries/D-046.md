1465	### D-046 — Face names are opaque string tokens; slash is reserved for structure
1466	
1467	**Status.** ratified
1468	
1469	**Position.** Face names = arbitrary strings; build invariants only no-`/` +
1470	per-assembly uniqueness; slash = structure, face names = opaque contract
1471	tokens; the periphery speaks face names on the *write* side ([D-083][d-083]); `exports`
1472	returns pairs like `connections`; `faces(asm, path; prefix, sep, except, only)`
1473	with dot-prefix *defaults* (convention, not law).
1474	
1475	**Spec.** [§8.6][s8-6], [§8.8][s8-8]
1476	
1477	**Rationale.** Recorded only through the rejections below.
1478	
1479	**Rejected.**
1480	- *Mandated dot convention:* a naming law where two invariants suffice.
1481	- *NamedTuple-returning `exports`:* `var"..."` noise for non-identifier names;
1482	  asymmetric with `connections`.
1483	- *Slash-composed prefixes:* face names would collide with structural path
1484	  notation.
1485	- *`rename` hooks in `faces`:* `exports` is ordinary code — map over the pairs.

3092	### D-101 — Implement replay as the ordinary loop with two substitutions
3093	
3094	**Status.** ratified
3095	
3096	**Position.** Replay: `replay!(sim, trace(sim0); to_boundary)` is the ordinary
3097	loop with exactly two substitutions — boundary zero initialized from the trace
3098	header, and the frame-top drain fed by the recording's batches keyed by frame
3099	ordinal (exact: the frame sequence is itself deterministic), applied verbatim
3100	with no surface re-check (the write-surface rule ran at recording time).
3101	
3102	**Spec.** [§2.5][s2-5], [§12.7][s12-7], [§14.5][s14-5]
3103	
3104	**Rationale.** The header captures the resolved stores + slots after `apply!`
3105	and BEFORE the boundary-zero sequence — [§14.5][s14-5]'s end-of-sequence capture
3106	placement corrected, since a post-sequence capture would re-fire authored
3107	conditions onto already-latched state — and boundary zero is re-executed under
3108	replay, firings recomputed never recorded; replay ends `initialized`
3109	(replay-to-inspect, replay-to-k−1-then-`step!` error reproduction, `run!`
3110	continuation) and re-records its own trace (header inherited, bit-identical
3111	prefix); pacing/control plane unchanged (paced replay + visualizer = session
3112	playback); rostered devices run as snapshot readers, live staging never drained
3113	(`ReplayDiscardedStaging`); entry validation loud and up front
3114	(`ReplayHeaderMismatch`, `ReplayUnknownFace`), the same pass normalizing the
3115	interactive writer's sparse records to positional batches against the
3116	header's schemas ([D-107][d-107] — once, off the loop, so the replay drain applies
3117	compiled scatters exactly as the live drain); structural mismatch errors,
3118	parametric difference = the what-if replay (determinism promised,
3119	reproduction only against the identical build).
3120	
3121	**Rejected.**
3122	- *A `run!(sim; replay = trc)` flag:* replay replaces `init!` and swaps the
3123	  drain source — a lifecycle entry, not a run option; muddies [§12.6][s12-6]'s
3124	  mandatory-`init!` rule.
3125	- *A synthetic playback device staging recorded batches:* wall-clock staging
3126	  cannot hit recorded frame ordinals — reintroduces the scheduler-determined
3127	  input timing [§11.1][s11-1] indicts.
3128	- *Replay ending `stopped`:* kills inspect/step/continue.
3129	- *Re-checking write surfaces at replay drain:* claims are live-roster facts of
3130	  the recorded session; re-derivation would discard valid recorded writes.
3131	- *Header = the authored sparse condition:* [§14.5][s14-5]'s old wording — silently
3132	  replays a different initial state after an `init_*` default edit, [D-038][d-038]'s
3133	  trap.

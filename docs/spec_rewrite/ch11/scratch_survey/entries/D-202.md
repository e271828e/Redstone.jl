7386	### D-202 — Stage batches as values plus touched-mask, never union tuples
7387	
7388	**Status.** ratified
7389	
7390	**Position.** The batch a staging cell holds is a pair of positional tuples
7391	over the claim set: a concretely typed values tuple `Tuple{T₁, …, Tₙ}` and a
7392	parallel `Bool` touched-mask, with untouched positions carrying placeholder
7393	values that the mask guard keeps dead. This amends [D-104][d-104]: its coalescing
7394	policy, `stage!`-side normalization, staging-sited diagnostics and
7395	schema-in-roster-entry all stand; only the batch's carrier changes, from the
7396	`Union{Nothing,T}` positional tuple to values-plus-mask.
7397	
7398	**Spec.** [§11.4][s11-4], [§11.5][s11-5]
7399	
7400	**Rationale.** The union carrier falsifies [§11.4][s11-4]'s own drain guarantee. Its
7401	per-element unions are isbits, but the batch *type* is not concrete: tuple
7402	types are covariant and `Nothing` is a zero-size singleton, so each combination
7403	of touched faces is its own concrete type with its own memory layout. The
7404	frame-top scatter then cannot be compiled once at attach — applying a batch
7405	dispatches on which faces it touched, every never-seen combination compiles a
7406	fresh specialization inside the frame (milliseconds, against a 2ⁿ pattern
7407	space), and even the warmed path boxes per drain. Width adds a second cliff:
7408	past 32 faces the positional merge leaves Julia's small-tuple path for a
7409	type-unstable, allocating fallback. Values-plus-mask restores one concrete
7410	isbits layout per writer: one scatter specialization compiled at attach,
7411	element loads as direct field reads, and a drain measured allocation-free at
7412	200 faces regardless of sparsity pattern (prototype, 2026-08-26). The recorded
7413	costs: every staged batch is claim-set-wide, so a sparse stage on a wide writer
7414	allocates the full-width cell box (only the greedy writer's width approaches
7415	the root's, and staging already pays one allocation per stage); and untouched
7416	positions need a constructible exemplar, which the declaration's probe values
7417	already supply.
7418	
7419	**Rejected.**
7420	- *Superseded position — the `Union{Nothing,T}` carrier ([D-104][d-104]):* the marker
7421	  rides in the value, which reads directly, but the non-concrete batch type
7422	  turns the drain into runtime specialization and boxing; the pattern-JIT
7423	  stalls surface only under a wide writer varying its touched set, the exact
7424	  migrated-GUI configuration.
7425	- *Keeping the union carrier and dispatching the scatter on the cell's `Ref` (a
7426	  concrete type):* kills the per-pattern compilation but not the boxing — with
7427	  no uniform layout, every touched element's load takes the generic field path;
7428	  a half-measure that would still need replacing.
7429	- *In-band sentinels per slot type (`NaN` and kin) instead of a mask:* collides
7430	  with legitimate levels and does not exist for every declared type; the mask
7431	  is out-of-band by construction.
7432	- *Precompiling every sparsity pattern at attach:* 2ⁿ specializations;
7433	  unpayable beyond toy widths.

849	### D-023 — Snapshot publication via atomic acquire-release
850	
851	**Status.** ratified
852	
853	**Position.** Snapshot publication: build private → release-store `@atomic
854	latest`; readers acquire-load; wait-free both ways; nothing reachable from a
855	published snapshot ever written again; allocate per boundary; log = retained
856	snapshot references.
857	
858	**Spec.** [§10.3][s10-3], [§11.2][s11-2]
859	
860	**Rationale.** Recorded only through the rejections below.
861	
862	Annotation (2026-10-02): the reader rule its third rejection points at is
863	stated in [D-293][d-293]'s Position.
864	
865	**Rejected.**
866	- *Preallocated snapshot rings:* reintroduce the reader-liveness reclamation
867	  proof the GC already provides.
868	- *`deepcopy` `SavingCallback` logging:* the capture *is* the publication
869	  mechanism.
870	- *Mid-step publication:* see [§10.3][s10-3].

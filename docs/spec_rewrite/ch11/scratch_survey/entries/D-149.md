5296	### D-149 — Check slot totality wherever a virgin world is established
5297	
5298	**Status.** ratified
5299	
5300	**Position.** **Slot totality is checked at every application that establishes
5301	a complete world over virgin stores — `init!`, trim setup, trim commit** — one
5302	class, one mechanism, one `UninitializedSlots` kind, collected and
5303	declaration-ordered; the governing principle replaces the enumeration.
5304	
5305	**Spec.** [§11.3][s11-3], [§9.3][s9-3], [§14.6][s14-6], [§14.8][s14-8], [Appendix B][sB], [§D.8][sD-8]
5306	
5307	**Rationale.** A round-5 kernel dry-run finding (finding 4; [§11.3][s11-3], [§9.3][s9-3],
5308	[Appendix B][sB] and [§D.8][sD-8] swept), amending [D-068][d-068]'s two-site placement. Coverage is a
5309	**plan-level fact** — the check compares the resolved plan's slot coverage
5310	against the `Build`'s `input_faces`, both resolution-time data — so the setup
5311	check costs one comparison and runs *before the first evaluation*, not merely
5312	before a write. [§14.8][s14-8]'s raw scratch instantiation is thereby sound **because**
5313	of the check: setup's checked totality guarantees every slot written before any
5314	read. And since commit applies the same composite over the same `baseline` as
5315	setup (`override(baseline, condition(d*))`, coverage identical), commit's
5316	totality check is structurally unfailable *through the trim path* — it remains
5317	as the shared `init!`-boundary defense, no `TrimReport` committed flag exists
5318	or is needed, and [§14.8][s14-8]'s no-throw doctrine holds without exception. [§14.6][s14-6]'s
5319	no-third-branch ban on `probe_value` is untouched.
5320	
5321	**Rejected.**
5322	- *`probe_value`-filling the scratch slots:* the [§14.6][s14-6] ban stands — it would
5323	  silently manufacture a world instead of diagnosing the incomplete one — a
5324	  fabricated zero is a fine probe input and a terrible flight condition.
5325	- *Trusting the `baseline`, per the prior literal text:* the finding's
5326	  divergence — an entire solve against undefined inputs — for a `Bool` slot an
5327	  undefined byte, UB rather than a wrong value — with the `UninitializedSlots`
5328	  diagnostic arriving only at commit, after the expensive part is sunk, and a
5329	  converged-but-uncommittable solve left with no reporting channel.
5330	- *A `committed` flag on `TrimReport` carrying commit-time totality failure:*
5331	  treats the symptom, institutionalizes discarding converged work against the
5332	  no-throw doctrine's own grain, and is dead surface once setup's check makes
5333	  the failure unreachable.

2279	### D-074 — Hand off component-function arguments as one named bundle
2280	
2281	**Status.** ratified
2282	
2283	**Position.** Named-bundle hand-off: every component function is `fn(comp,
2284	args)` — one NamedTuple bundle of zero-copy views, destructured by name in the
2285	signature; `project(comp, x)` alone stays positional.
2286	
2287	**Spec.** [§5.2][s5-2], [§7.3][s7-3], [§8.2][s8-2], [§11.4][s11-4], [§13.2][s13-2]
2288	
2289	**Rationale.** The bundle law (a field exists iff the store or tier fact
2290	exists: undeclared stores absent, never `nothing`-filled; `t` everywhere, `Δt`
2291	discrete-only, `ws` iff `workspace` declared); closed per-function-kind name
2292	sets, growth = a decision-log event; probe failures carry did-you-mean against
2293	the legal set, synthesized from a `FieldError` (structured: type + field as
2294	data, Julia ≥ 1.12) matched against the bundle's own NamedTuple type — no
2295	message-text scraping, the bundle staying a bare NamedTuple, a getproperty
2296	wrapper the recorded fallback.
2297	
2298	**Rejected.**
2299	- *Positional signatures + a clock-view type:* dead slots written unread,
2300	  un-droppable mid-list holes; the view type subsumed by naming.
2301	- *Keyword arguments via `Base.kwarg_decl` reflection:* a relied-on seam on an
2302	  internal binding — the [D-017][d-017] `task_local_storage` lesson.
2303	- *Keyword + `_...` slurp:* permanent noise; "signature = read-set" weakens to
2304	  "at least".
2305	- *One context object carrying workspace too:* grab-bag accretion; mutable
2306	  member muddies the immutable-views teaching.
2307	- *Time as a wired `Clock` component:* time is ambient in `f`/output
2308	  stages/guards/handlers — two access idioms for one quantity.
2309	- *`nothing`/`(;)` padding for undeclared stores:* defers the error from
2310	  destructuring to first field access, with a worse message.
2311	- *A `comp.Δt` virtual property:* [D-019][d-019] — the period is a schedule-position
2312	  fact, and `===`-identical siblings may sit under different `rates` keys.
2313	- *Positional signatures, additionally:* leave the `t`/`Δt` scalar pair
2314	  swappable without any error, both being bare same-typed reals.

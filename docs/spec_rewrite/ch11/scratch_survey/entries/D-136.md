4384	### D-136 — Unify diagnostics and liveness heartbeat into one per-writer diagnostic cell
4385	
4386	**Status.** ratified
4387	
4388	**Position.** Closing [D-133][d-133]'s [§13.2][s13-2] deferral, the runtime diagnostic stream and
4389	the liveness heartbeat get one mechanism — **one per-writer diagnostic cell**,
4390	one per rostered device plus one for the loop itself, single-writer by the same
4391	ownership argument as [§11.4][s11-4]'s staging cells (no lock, no arbitration, no new
4392	primitive), holding a **bounded ring of 16 diagnostic values plus per-kind
4393	suppressed counts** and an atomic heartbeat timestamp.
4394	
4395	**Spec.** [§9.8][s9-8], [§10.7][s10-7], [§11.1][s11-1], [§11.2][s11-2], [§11.4][s11-4], [§11.6][s11-6], [§11.8][s11-8], [§12.2][s12-2], [§12.4][s12-4], [§13.2][s13-2], [§13.5][s13-5],
4396	Appendices C/D
4397	
4398	**Rationale.** The bound **is** the rate limit — an emission past capacity
4399	within a frame is not stored and its kind's count increments, earliest-in-frame
4400	retained — which homes [§13.2][s13-2]'s "rate-limited wherever its source can repeat" as
4401	a structural property of the channel and discharges [D-133][d-133]'s deferral with no
4402	constant to tune. The loop takes each cell with `atomicswap` at the **frame-top
4403	drain**, [§11.4][s11-4]'s own point, swapping in a **shared empty sentinel** so a quiet
4404	frame allocates nothing and no load-only path goes untested; the heartbeat
4405	rides in the same cell — stored on every loop pass from inside the handle
4406	primitives ([§11.6][s11-6]), acquire-loaded at the drain, [§12.2][s12-2]'s 2 s staleness read
4407	against this field, and not a diagnostic kind. The published **framework status
4408	becomes a concrete frozen value**: per writer `recent` (this boundary's drained
4409	ring), `suppressed` (the per-kind counts the ring refused this boundary),
4410	`totals` (loop-owned cumulative per-writer × per-kind counters, *copied* into
4411	each status) and `heartbeat`, beside [§10.7][s10-7]'s pacer diagnostics — [§11.2][s11-2]'s binding
4412	rule holding **by construction**, since the swap gives the loop exclusive
4413	ownership of the batch before publication and the live accumulator is never
4414	reachable from a snapshot. Presentation is separated from channel policy:
4415	renderers print a writer × kind up to **25 cumulative occurrences** and then
4416	switch to count-only display (the `maxlog` successor), counts accumulating
4417	regardless; and the **terminal snapshot carries the final cumulative counters**
4418	([§12.4][s12-4](1), [§13.5][s13-5]), so an unattended run's complete diagnostic account survives
4419	its own shutdown. The allocation story is spec-stated: a quiet frame adds
4420	**zero heap allocation**, the per-writer status riding inline in the
4421	per-boundary snapshot allocation [§11.2][s11-2] already accepted — which requires the
4422	per-kind counters to be a **fixed-shape isbits record, never a `Dict`**,
4423	licensed by [Appendix C][sC]'s closed kind set — while a noisy frame allocates its
4424	values at emission on the writer's own task and a **fresh ring** lazily at the
4425	writer's next emission (the drained one being frozen into a snapshot and
4426	unwritable thereafter), the same GC-over-reuse trade [§11.2][s11-2] made when it rejected
4427	preallocated snapshot buffers; worst case per writer per boundary is therefore
4428	one ring of 16, everything past it an integer increment, and [§9.8][s9-8]'s scoped
4429	model-sweep zero-allocation invariant is untouched. Composition note, recorded
4430	once: `totals` is monotone across logged snapshots, so `log_every` decimation
4431	loses *which* boundary in a skipped stretch an occurrence fell on, never *how
4432	many*.
4433	
4434	**Rejected.**
4435	- *A shared queue or buffer under a lock:* cross-task contention on the loop's
4436	  own frame path and no single-writer ownership to reason from — the arbitrary
4437	  shared mutable state [§11.1][s11-1]'s two rules exist to eliminate, reintroduced for
4438	  the one structure that had escaped specification.
4439	- *A status referencing the live accumulator:* the cheapest thing to write and
4440	  a direct violation of [§11.2][s11-2]'s binding rule — a reader walking a structure its
4441	  writer is still mutating.
4442	- *Ring reuse by double-buffering:* reintroduces exactly the reader-liveness
4443	  proof the GC provides for free — [§11.2][s11-2]'s own argument against preallocated
4444	  snapshot buffers — to save an allocation incurred only on frames already
4445	  doing something unusual.
4446	- *Unbounded accumulation:* an unattended run with no status reader grows
4447	  without bound, precisely the configuration the framework must survive, and a
4448	  bound is what gives the drop policy a definition.
4449	- *A separate heartbeat channel or liveness registry:* a second cross-task
4450	  structure with the same writers, the same ownership question and the same
4451	  drain point, for one timestamp.
4452	- *A per-device rate-limit constant, [D-133][d-133]'s deferred option:* the structure
4453	  carrying the stream already bounds it — a tunable would name a policy the
4454	  channel cannot violate anyway.
4455	- *A render threshold baked into the channel:* what is recorded must not depend
4456	  on who is looking; 25 is a renderer's number.

7435	### D-203 — The termination record carries typed sources and the tail residue
7436	
7437	**Status.** ratified
7438	
7439	**Position.** The run's termination record is a three-field value — the final
7440	boundary time, absent when no boundary ever ran; a typed source; the tail
7441	residue — and this amends [D-201][d-201]'s disposal clause: the run's-end sweep folds
7442	the residue into the record *and* presents it through the logging backend,
7443	still never published. The bundled rulings:
7444	
7445	- The sources follow the diagnostic kind convention — kind is identity,
7446	  payload plain data ([§13.2][s13-2]) — without joining [Appendix C][sC]'s diagnostic set:
7447	  `EndTimeReached` (no payload), `ModelRequestedStop` (the holding face),
7448	  `ControlRequestedStop` (its issuer), and `LoopError` (the propagated
7449	  cause). The record covers `errored` exactly as it covers `stopped` ([§13.6][s13-6]).
7450	- The operator interrupt stays a tag on an ordinary stop ([§13.5][s13-5]): the
7451	  `:interrupt` issuer arm of `ControlRequestedStop`, never a fifth kind.
7452	- The control-plane stop word carries its issuer — the requesting device,
7453	  `:code`, or `:interrupt` — written by compare-and-swap from empty,
7454	  first writer wins ([§12.1][s12-1]).
7455	- `DeviceJoinTimeout` becomes an ordinary structured kind: written to the
7456	  loop's own cell in tail step (5), collected by the run's-end sweep
7457	  ([§12.4][s12-4], [Appendix C][sC]).
7458	- Source consultation order is normative: a pending control stop at frame
7459	  top, then `t_end`, then the stop faces at each publication — the recorded
7460	  source of a boundary where two hold is the first in that order.
7461	- `init!` clears the record with the trajectory ([§12.6][s12-6]).
7462	
7463	**Spec.** [§11.8][s11-8], [§12.1][s12-1], [§12.4][s12-4], [§12.6][s12-6], [§13.5][s13-5], [§13.6][s13-6], [Appendix C][sC]
7464	
7465	**Rationale.** [D-201][d-201] disposed of the tail window's diagnostics through
7466	presentation because the termination record did not yet exist as machinery;
7467	with it on the bench, presentation-only fails the unattended run — [§11.8][s11-8]'s own
7468	audience for the terminal counters. Once `run!` returns, "did a device hang
7469	the join?" was answerable only by whoever captured the log stream, and a
7470	harness exercising the abandonment path had to scrape logs. The record is
7471	none of [D-201][d-201]'s three rejected disposals, which all stand: it is not a
7472	publication — it follows no boundary sequence and sits on no data plane — it
7473	is not cell retention across runs (`init!` clears it with the trajectory), and
7474	it is not a drop. It is stopped-sim state on the diagnostic-observation side
7475	of [§13.5][s13-5]'s own doctrine, and the precedent of carrying failure detail was
7476	already spent when the abnormal path put the cause exception in the record.
7477	The typed sources apply [§13.2][s13-2]'s convention to the outcome channel, dissolving
7478	a flat record whose `exception` field applied only to the error case and
7479	whose `face` field only to the stop-face case; construction simplifies with
7480	them, the loop returning a source where it detects one and the record
7481	assembled once, in the outermost `finally`, after the sweep has the residue
7482	in hand. Issuer attribution is nearly free: every stop site knows its
7483	identity — the handle carries the device name, the interrupt is caught at a
7484	known unmask point — and the anonymous `Bool` was discarding it at the moment
7485	of writing; first-CAS-wins matches the first-`true` doctrine for stop faces
7486	and names the request that actually initiated the tail. The residue stays
7487	bounded by construction: one final ring take per writer, at most sixteen
7488	entries plus suppressed counts. The record's cost is nil on any path that
7489	matters — it is built once per run, on the cold side of the final snapshot.
7490

7492	sentence states it today, so the fourth rejection's citation has no referent.
7493	The rejection's other grounds stand.

7495	Annotation (2026-10-08): amended by [D-316][d-316]. Stop requests replace the stop
7496	faces. `ModelRequestedStop` carries the requester's path, port and reason,
7497	and the source order reads the requests at each publication where it read
7498	the faces. Two requests at one boundary resolve to the first in roster order.
7499	
7500	**Rejected.**
7501	- *Superseded position — presentation-only disposal ([D-201][d-201]):* honest but
7502	  ephemeral; the tail's facts evaporated from the program at the moment it
7503	  regained control. [D-201][d-201]'s rejected list never weighed the record, which
7504	  had not been built when it was adjudicated.
7505	- *A fifth source kind for the interrupt:* [§13.5][s13-5] rules the interrupt a tag on
7506	  an ordinary stop — nothing failed; a consumer that cares matches on the
7507	  issuer, and a distinct type would quietly reverse a settled ruling for no
7508	  gain.
7509	- *A flat record with `nothing`-padded per-source fields (the prototype's
7510	  first cut):* the shape [§13.2][s13-2] rejects for diagnostics — most fields
7511	  meaningless for most sources, tests matching on a `Symbol` instead of a
7512	  type.
7513	- *`Float64` time with `NaN` for "no boundary ever ran":* time is generic —
7514	  the clock is seeded `zero(T)` ([§7.2][s7-2]) — and `NaN` is an in-band sentinel of
7515	  the species [D-202][d-202] rejects; absence spelled out-of-band instead.
7516	- *Carrying the configured `t_end` in `EndTimeReached`'s payload:* the
7517	  effective policy already lives in the run metadata ([§11.5][s11-5], [§13.5][s13-5]); a second
7518	  home for a fact that has one.
7519	- *Termination sources as [Appendix C][sC] diagnostics:* the record is outcome, not
7520	  warning — three of the four sources are healthy ends, and the interrupt
7521	  sentence in [§13.5][s13-5] already ruled the appendix gains nothing here.

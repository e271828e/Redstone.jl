3193	### D-104 — Coalesce staged writes by CAS merge with per-attachment positional shape
3194	
3195	**Status.** ratified
3196	
3197	**Position.** Staged representation and coalescing: one policy — CAS merge,
3198	newest wins per face (merge is always correct: complete writers get overwrite's
3199	result, sparse writers are protected from its lost-write bug); enumerated
3200	writers get a per-attachment fixed shape compiled at attach — positional tuple
3201	over the claim set, `Union{Nothing,T}` isbits per face, `nothing` = not touched
3202	(never reset), schema in the roster entry — giving positional merge, an
3203	attach-compiled drain scatter (mirror of [§11.2][s11-2]'s gather), and `stage!`-side
3204	normalization (name → position, convert, fill `nothing`) so authors return
3205	sparse face ⇒ value pairs and the name-shaped dynamism is confined to one
3206	framework conversion on the device task.
3207	
3208	**Spec.** [§11.2][s11-2], [§11.4][s11-4]
3209	
3210	**Rationale.** The interactive writer gets the same treatment under the [D-106][d-106]
3211	freeze — positional shape over the unclaimed set, recompiled at each
3212	stopped-sim `attach!`/`detach!` (which also renormalizes pending batches:
3213	reshape, discard newly-claimed faces with `ClaimedFaceEntry`) — one
3214	representation, no name resolved inside the loop's frame; diagnostic sites all
3215	at staging — `OutOfClaimEntry`, `ClaimedFaceEntry`, `EntryTypeMismatch` — and
3216	the drain checks nothing ([D-106][d-106]); trace records match batch density ([D-107][d-107]);
3217	user-proposed shape (fixed tuple with `nothing` markers), framework-relocated
3218	normalization.
3219	
3220	**Rejected.**
3221	- *Name-keyed interactive batches, the earlier design of record:* justified
3222	  only by the mid-session-mutable surface the [D-106][d-106] freeze removed.
3223	- *The `complete(binding)` overwrite opt-in, drafted then dropped:* under
3224	  positional merge the fast path saves a pending-read and a tuple rebuild on
3225	  the device task — not worth a declarable promise whose false direction loses
3226	  writes; supersedes the earlier attach-flag sketch.
3227	- *Author-built total tuples:* a padding form — the [D-074][d-074] / handler-return-law
3228	  disease.
3229	- *Name-keyed batches everywhere:* dynamic dispatch in the drain, inside the
3230	  loop's frame.
3231	- *One build-wide shape over all root faces:* trace memory inflates by
3232	  faces/entries, and only the interactive writer would need it.

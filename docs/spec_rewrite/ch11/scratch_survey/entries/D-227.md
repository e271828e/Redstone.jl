8562	### D-227 — Select the stepper by type under the `algorithm` keyword
8563	
8564	**Status.** ratified
8565	
8566	**Position.** The deployment keyword that picks the integration backend is
8567	`algorithm`, and its value is a stepper type, `RK4` by default, which binding
8568	materializes against the flat state buffer. The name reaches every surface
8569	that records the choice: the trace header's deployment block, the replay
8570	comparison and the `DeploymentInvalid` parameter.
8571	
8572	**Spec.** [§9.2][s9-2], [§10.2][s10-2], [§11.5][s11-5], [Appendix B][sB], [Appendix C][sC]
8573	
8574	**Rationale.** The code took `method = RK4` and [Appendix B][sB] spelled
8575	`algorithm = RK4()`, with no ruling behind either. The two spellings differ
8576	on two axes. On the value, a stepper is a runtime object owning scratch sized
8577	to the state and typed by the deployment scalar, and both are known only at
8578	binding: `N` comes out of compilation, `T` is the constructor's positional
8579	argument. A type is called with `(T, N)` once both are in hand. An instance
8580	would have to be a token that binding later materializes, a spec type per
8581	backend plus a materialization protocol, and neither first-cut backend
8582	carries a parameter for the token to hold. The instance form pays off only
8583	for a parametrized backend, which [§10.2][s10-2] defers under the guarded-additions
8584	rule, and admitting one later is an extension by dispatch on the keyword's
8585	value, never a break. Selecting by type is also the constructor's existing
8586	idiom: the scalar is selected the same way. On the name, "method" in Julia
8587	and throughout the package's own commentary means a method of a generic
8588	function, so a diagnostic naming `:method` as an invalid deployment parameter
8589	reads as a dispatch complaint. `algorithm` is the spec's majority term and
8590	the glossary's, and carries no such collision.
8591	
8592	**Rejected.**
8593	- *`algorithm = RK4()`, the instance form:* builds a materialization layer for
8594	  backends that have nothing to parametrize; deferred with the parametrized
8595	  backend it would serve.
8596	- *Keep `method` and sweep the spec:* cheapest today, but fixes the
8597	  vocabulary collision on a keyword, a header field and a diagnostic
8598	  permanently.
8599	- *`stepper = RK4`:* the most precise word, but the spec uses "stepper" for
8600	  the seam and the runtime object, and the keyword selects an identifier of
8601	  the choice, not the object.

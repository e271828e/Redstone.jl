1386	### D-044 — Slot exclusivity and the write-surface rule
1387	
1388	**Status.** ratified
1389	
1390	**Position.** Slot exclusivity: one writer per root slot at a time; device
1391	claims at attach, conflict = attach-time error, release on detach; per-device
1392	cells/CAS/drain retained for atomicity and coalescing. Generalized as the
1393	write-surface rule ([§11.3][s11-3]): an entry reaches a slot iff the face is inside the
1394	writer's surface, else discard + warn — under the [D-106][d-106] roster freeze every
1395	surface is static per run, so all checks run at staging and the drain checks
1396	nothing; enumerated surfaces (a device's claim set — binding-bounded even on
1397	unclaimed faces, `OutOfClaimEntry`) vs. the derived interactive surface (GUI +
1398	`stage!`: the unclaimed set, shared, re-derived only at stopped-sim roster
1399	changes — a write to a claimed face is `ClaimedFaceEntry` at staging;
1400	`StaleInteractiveEntry` and its moved-between-staging-and-drain scenario are
1401	dead); autonomous opportunistic writing does not exist, so cross-writer races
1402	structurally cannot arise and drain order stays diagnostic.
1403	
1404	**Spec.** [§11.3][s11-3], [§11.6][s11-6], [§11.7][s11-7]
1405	
1406	**Rationale.** Recorded only through the rejections below.
1407	
1408	**Rejected.**
1409	- *Cross-device attachment-order precedence as conflict policy:* resolves races
1410	  the C172X demo's cast (`flight_case_studies.md`) shows nobody wants — every dual writer is a stream shadowed by
1411	  a mirror.
1412	- *FlightCore-style concurrent multi-device writing of one input:* a bug
1413	  surface, not a feature.
1414	- *Discard-outside-the-claim as literal drain rule:* an empty claim set would
1415	  discard every GUI write.
1416	- *Ownership-only discard (claimed-by-another):* leaves enumerated bindings
1417	  unenforced at the drain and reopens unclaimed multi-writer races.
1418	- *Unclaimed-surface opportunism "for any device":* reinstates the rejected
1419	  attachment-order policy; breaks [§11.7][s11-7]'s stays-put and sole-writer arguments.

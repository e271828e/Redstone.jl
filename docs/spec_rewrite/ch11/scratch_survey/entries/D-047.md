1487	### D-047 — Stage widgets on interaction events, not every pass
1488	
1489	**Status.** ratified
1490	
1491	**Position.** Widgets stage on interaction events only (value widgets on edit,
1492	edge widgets on activation with peek-computed counter levels); levels ×
1493	own-pending-first peek give idempotent repeat and correct multi-click; snapshot
1494	includes root slots (peek fallback + read-only mirrors); trace header extends
1495	to initial slot values; engage semantics stay in the FCS (the existing
1496	`ControlLaws` transition latch — uniform across writers), GUI peek-batch
1497	demoted to display-sync sugar.
1498	
1499	**Spec.** [§11.3][s11-3]
1500	
1501	**Rationale.** No claim-transition policy exists — mid-run claim transitions
1502	cannot occur under the [D-106][d-106] freeze, liveness is baked once per run, and the
1503	orphan case (claiming device's task dead) renders in the widget's source label.
1504	
1505	**Rejected.**
1506	- *Stage-every-pass:* motivating contest died with exclusivity; as insurance it
1507	  masks invariant violations at render rate — anti-diagnostic; render-rate
1508	  trace noise.
1509	- *Held-button re-staging:* auto-repeat at frame rate once the snapshot catches
1510	  up.
1511	- *Capture-on-engage as a GUI/framework obligation:* already aircraft design,
1512	  shipped in `ControlLaws`.
1513	- *Slot-initial-values as export-entry defaults:* trim writes slot values it
1514	  *solved for* — services own initialization.

3059	### D-101 — Implement replay as the ordinary loop with two substitutions
3060	
3061	**Status.** ratified
3062	
3063	**Position.** Replay: `replay!(sim, trace(sim0); to_boundary)` is the ordinary
3064	loop with exactly two substitutions — boundary zero initialized from the trace
3065	header, and the frame-top drain fed by the recording's batches keyed by frame
3066	ordinal (exact: the frame sequence is itself deterministic), applied verbatim
3067	with no surface re-check (the write-surface rule ran at recording time).
3068	
3069	**Spec.** [§12.7][s12-7], [§14.5][s14-5]
3070	
3071	**Rationale.** The header captures the resolved stores + slots after `apply!`
3072	and BEFORE the boundary-zero sequence — [§14.5][s14-5]'s end-of-sequence capture
3073	placement corrected, since a post-sequence capture would re-fire authored
3074	conditions onto already-latched state — and boundary zero is re-executed under
3075	replay, firings recomputed never recorded; replay ends `initialized`
3076	(replay-to-inspect, replay-to-k−1-then-`step!` error reproduction, `run!`
3077	continuation) and re-records its own trace (header inherited, bit-identical
3078	prefix); pacing/control plane unchanged (paced replay + visualizer = session
3079	playback); rostered devices run as snapshot readers, live staging never drained
3080	(`ReplayDiscardedStaging`); entry validation loud and up front
3081	(`ReplayHeaderMismatch`, `ReplayUnknownFace`), the same pass normalizing the
3082	interactive writer's sparse records to positional batches against the
3083	header's schemas ([D-107][d-107] — once, off the loop, so the replay drain applies
3084	compiled scatters exactly as the live drain); structural mismatch errors,
3085	parametric difference = the what-if replay (determinism promised,
3086	reproduction only against the identical build).
3087	
3088	**Rejected.**
3089	- *A `run!(sim; replay = trc)` flag:* replay replaces `init!` and swaps the
3090	  drain source — a lifecycle entry, not a run option; muddies [§12.6][s12-6]'s
3091	  mandatory-`init!` rule.
3092	- *A synthetic playback device staging recorded batches:* wall-clock staging
3093	  cannot hit recorded frame ordinals — reintroduces the scheduler-determined
3094	  input timing [§11.1][s11-1] indicts.
3095	- *Replay ending `stopped`:* kills inspect/step/continue.
3096	- *Re-checking write surfaces at replay drain:* claims are live-roster facts of
3097	  the recorded session; re-derivation would discard valid recorded writes.
3098	- *Header = the authored sparse condition:* [§14.5][s14-5]'s old wording — silently
3099	  replays a different initial state after an `init_*` default edit, [D-038][d-038]'s
3100	  trap.

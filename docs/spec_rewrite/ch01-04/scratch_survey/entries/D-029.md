964	### D-029 — Input trace on by default
965	
966	**Status.** ratified
967	
968	**Position.** Input trace on by default, cleared at `init!`, plain kill switch.
969	
970	**Spec.** [§11.2][s11-2], [§11.5][s11-5], [Appendix B][sB]
971	
972	**Rationale.** Recorded only through the rejections below.
973	
974	**Rejected.**
975	- *Opt-in:* the trace is primary data — the log is recomputable from it, never
976	  the reverse; the session you need replayed is the one you didn't plan to
977	  record.
978	- *Tying trace to the log switch:* conflates primary and derived recording.
979	- *Rolling window/sampling:* complexity without a customer.

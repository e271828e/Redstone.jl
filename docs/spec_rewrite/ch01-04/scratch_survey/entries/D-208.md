7649	### D-208 — Root inputs are the root component's input faces, whatever its class
7650	
7651	**Status.** ratified
7652	
7653	**Position.** The build accepts any component as root, and the model's root
7654	inputs are the root's input faces uniformly. The bundled rulings:
7655	
7656	- For an assembly they are its `input_connections` keys, each traced
7657	  through the total face chain ([D-207][d-207]) to leaf input entries; for a
7658	  primitive, its `input_types` keys directly — [D-172][d-172]'s kind-blind faces
7659	  applied at the root.
7660	- Types keep their derivation (the ultimate consuming entry at the
7661	  activation scalar, [§8.2][s8-2]'s tight-bound rule; a primitive root's face is its
7662	  own consuming entry), and [§8.2][s8-2]'s primitive-root refusal is retired.
7663	- Abstract-at-root is unchanged: a primitive with an abstract input entry
7664	  still cannot be built bare, and the component test rig ([§13.7][s13-7]) keeps its
7665	  stubbing role, losing only its gate status.
7666	
7667	**Spec.** [§6.1][s6-1], [§8.2][s8-2], [§8.6][s8-6], [§9.1][s9-1], [§9.3][s9-3], [§11.3][s11-3], [§13.7][s13-7]
7668	
7669	**Rationale.** The refusal existed because no rule made a primitive root's
7670	unfed inputs root inputs; the uniform doctrine supplies one with no new
7671	vocabulary, and the one-child wrapper it forced on leaf exercise added a
7672	level of ceremony without adding information.
7673	
7674	**Rejected.**
7675	- *Keeping the assembly-only root:* with the doctrine uniform, the
7676	  remaining justification was the rig idiom, which survives on its own
7677	  merits.

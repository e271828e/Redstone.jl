1165	### D-036 — Table mechanics: stage returns are NamedTuples of port values
1166	
1167	**Status.** ratified
1168	
1169	**Position.** Table mechanics: stage returns are NamedTuples of port values;
1170	aggregate `y` = virtual merge, gathered per call, never stored; custom structs
1171	are port values — one port, one cell, atomic in wiring; granularity guideline:
1172	bundle what shares a stage and is consumed together.
1173	
1174	**Spec.** [§4.3][s4-3]
1175	
1176	**Rationale.** Recorded only through the rejections below.
1177	
1178	**Rejected.**
1179	- *Bare-struct returns with field-splatting:* ambiguous, type-lossy merge,
1180	  reflection-hungry. "Type-lossy" spelled out: neither the struct type nor the
1181	  methods that justify its existence can be reassembled from a flat merged
1182	  namespace.
1183	- *Sub-field wiring:* the port stops being the atomic unit; field-projection
1184	  connector kept as guarded addition.
1185	- *Per-field cells for struct internals:* nested display is a lazy view, not
1186	  storage.

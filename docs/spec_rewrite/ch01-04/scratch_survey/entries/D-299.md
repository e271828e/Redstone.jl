12643	### D-299 — Rate scopes by type, the feed-list doctrine and the helper pair
12644	
12645	**Status.** ratified
12646	
12647	**Position.** Five rulings that [§8.7][s8-7] and [§8.8][s8-8] state are fixed here.
12648	
12649	- A `sample_times` declaration belongs to the assembly type, not to the
12650	  child instance, because the ratio it declares is type-intrinsic, never a
12651	  per-instance value.
12652	- Adding a channel to a feed list is one edit: the new pair creates the wire
12653	  and removes the face from the input face surface at once. The two
12654	  declarations cannot drift, because neither holds the shared names, so the
12655	  drift class is removed rather than detected. The single source must be
12656	  authored data, never inferred structure.
12657	- The passthrough helpers come in a pair, `input_passthrough` and
12658	  `output_passthrough`, and the name carries the direction. After the
12659	  boundary declarations split by direction, a single call cannot emit
12660	  entries into two declarations.
12661	- `output_passthrough`'s consumer is one-level routing. Every level
12662	  re-exports the outputs it surfaces, so the output side needs the computed
12663	  spelling the input side already has.
12664	- At a root input, scalar faces make partial scripting compose. A bundled
12665	  face there collides with [§4.3][s4-3]'s write-side granularity and forfeits
12666	  partial scripting.
12667	
12668	**Spec.** [§8.7][s8-7], [§8.8][s8-8]
12669	
12670	**Rationale.** Each bullet restates what an existing entry recorded outside
12671	its Position. The type-intrinsic ratio was recorded in [D-042][d-042]'s Rejected
12672	list. The one-edit feed list and the removed drift class were recorded in
12673	[D-145][d-145]'s Rationale, and authored data over inferred structure in its Rejected
12674	list. The helper pair was recorded in [D-171][d-171]'s Rationale, and one-level
12675	routing as `output_passthrough`'s consumer in [D-209][d-209]'s. Scalar faces at a root
12676	input were recorded in [D-207][d-207]'s Rejected list.
12677	
12678	**Rejected.** None beyond the source entries' lists.

6137	### D-170 — Split assembly connections into child/input/output declarations
6138	
6139	**Status.** ratified
6140	
6141	**Position.** Assembly routing declarations renamed and split: `connections` →
6142	**`child_connections`** (strictly child-port → child-port, keeps the
6143	mandatory-even-empty assembly kind-marker role); `exports` **splits by
6144	direction** into **`input_connections`** (face => internal input path or
6145	tuple-of-paths fan-out; entry spelling unchanged) and **`output_connections`**
6146	(internal source path => face, now flow-ordered); direction is *declared by the
6147	method*, [D-041][d-041]'s endpoint derivation becoming a cross-check with a sharper
6148	error and the mixed-entry class inexpressible; face-name uniqueness spans both
6149	boundary declarations; one invariant spans all three: every pair's arrow points
6150	the way the signal flows, left = producer or entry point, right = consumer,
6151	every right side fed exactly once.
6152	
6153	**Spec.** [§3.3][s3-3], [§6.1][s6-1], [§6.2][s6-2], [§11.3][s11-3], [§8.1][s8-1], [§8.2][s8-2], [§8.5][s8-5], [§8.6][s8-6], [§8.8][s8-8], [§9][s9], [§13.3][s13-3]
6154	(swept)
6155	
6156	**Rationale.** Supersedes [D-041][d-041]'s single-method shape; [D-039][d-039]'s marker role
6157	transfers. Motivation: the old `exports` held two opposite flow directions in
6158	one list — spelling-uniform (face on left) at the price of flow-uniformity, and
6159	any single mixed-direction list must sacrifice one.

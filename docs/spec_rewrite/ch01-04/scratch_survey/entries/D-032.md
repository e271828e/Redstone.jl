1022	### D-032 — Component declaration: trait layer with probe-checked schema authority
1023	
1024	**Status.** ratified
1025	
1026	**Position.** Component declaration: declarative trait layer in plain Julia
1027	(well-known functions returning plain values; stage functions ordinary
1028	methods); schema authority — declarations define, probe evaluation checks
1029	(build probe with real values + free always-on conformance); convenience macros
1030	addable a posteriori, never essential.
1031	
1032	**Spec.** [§7.2][s7-2], [§8.1][s8-1], [§8.3][s8-3], [§8.4][s8-4]
1033	
1034	**Rationale.** Recorded only through the rejections below.
1035	
1036	**Rejected.**
1037	- *Inference-by-evaluation as schema authority:* error locality inverts —
1038	  failures inside correct code; schemas sample/branch-dependent; annotations
1039	  homeless. The five [§8.4][s8-4] walkthroughs traced under inference-by-evaluation,
1040	  recorded as the grounding evidence: (1) a typo'd wire (`:throtle`) gives a
1041	  missing-field error inside a correct `h_xu` at probe time, the input set
1042	  silently *defined* by the typo; (2) a forgotten wire read only by a guard is
1043	  detected only if the probe exercises that guard, and then as a missing field
1044	  in event code; (3) a forgotten branch field yields a schema silently derived
1045	  from whichever branch the initial state took, then a mid-run error or a
1046	  silently absent port at the first transition; (4) a type mismatch surfaces as
1047	  a `MethodError` deep inside user math; (5) a typo'd return field silently
1048	  *defines* a new cell, the intended name's absence surfacing later as a
1049	  missing-field error inside correct `f`/guard code.
1050	- *Macro DSL as substrate:* opaque codegen, tooling/stack-trace tax, only ever
1051	  lowers to the trait layer.
1052	- *Optional declarations with inference fallback:* two idioms; the quick hacks
1053	  most likely to skip are most likely to harbor branch bugs.

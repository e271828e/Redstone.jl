4571	### D-139 — Give environment field handles a value-level constructor to prevent drift
4572	
4573	**Status.** ratified
4574	
4575	**Position.** Environment field handles get a **value-level constructor** — the
4576	map (component, input values) → handle exposed as a plain, pure, exported
4577	function (`atmospheric_field(atm; T_sl, p_sl, wind)` for the `SimpleAtmosphere`
4578	successor), with the component's swept output stage a **one-line call to it and
4579	never the reverse** — stated in [§4.4][s4-4] as a **shipped component's obligation**
4580	([Appendix A][sA] taught contract, [Appendix D][sD] entry), because only the component's
4581	author can write it: the real component composes sub-models, and anyone else
4582	reconstructing the map has re-created the silent-drift class [§5.3][s5-3] exists to
4583	kill.
4584	
4585	**Spec.** [§4.4][s4-4], [§5.3][s5-3], [§14.1][s14-1], [§14.2][s14-2], [§14.7][s14-7], [§14.9][s14-9], Appendices A/D
4586	
4587	**Rationale.** Bulk-data components owe only that the query math be *reachable*
4588	as a plain function; building a handle outside a build may then cost a resource
4589	load, acceptable because condition authoring is design-time code. [§14.1][s14-1]'s
4590	**caller-computable escape is extended to cover environment queries**: a
4591	condition needing one constructs the sweep's exact handle from the same values
4592	its `baseline` writes into the environment component's slots — or, in a rig
4593	where the handle *is* a root slot value, simply holds the value it wrote there
4594	— and calls the same query function the consuming component calls; one
4595	implementation of the field math evaluated one level up, no pre-sweep and no
4596	new mechanism. [§14.1][s14-1] also records the **environment-free fallback** through the
4597	existing second escape: promote the eliminated state coordinates to decision
4598	variables and enforce the targets as residuals on swept outputs, which needs no
4599	environment access at condition time at all (the detailed
4600	elimination-vs-enlargement material stays out of the spec — companion
4601	walkthrough, then `pending.md`). **Trim problems never author the environment** ([§14.7][s14-7],
4602	[§14.9][s14-9]): handles arrive through the user parameter record, the problem
4603	*receiving* the environment and never writing it, which is what keeps **one
4604	problem artifact valid across a full world and a thin rig** — a condition entry
4605	naming a wired input fails resolution by name, correctly ([§14.9][s14-9]), so a problem
4606	that wrote an environment face would apply only to rigs where that face happens
4607	to be unconnected. [§14.9][s14-9]'s "the aircraft is never literally the root" is
4608	**softened from doctrine to default**: leaving an environment face unconnected
4609	is legal by construction — the face becomes an ordinary root slot holding the
4610	handle *value*, written by the `baseline` like any other slot, the **test-rig
4611	idiom** and the function-valued sibling of a constant source — while
4612	`design_world(ac)` remains the shipped rig for design tasks, keeping the
4613	environment's tunables in the slot vocabulary that conditions, `capture`,
4614	linearization's input surface and the trace header already speak. [§9.6][s9-6]'s
4615	"`Kinematics.Initializer` … survives untouched, aircraft-side" is
4616	**corrected**: it survives aircraft-side with its `atmosphere::Model` argument
4617	respelled as a field handle (built at value level per [§4.4][s4-4], or held as a rig
4618	slot value). Recorded once, the orthogonal **2×2** the discussion established:
4619	*elimination vs. enlargement* (where target enforcement lives — closed-form in
4620	the condition math, or as residuals on swept outputs) × *component-produced vs.
4621	slot-held environment* (who owns the handle in the rig). Only the first axis
4622	decides whether a **second handle path exists at all**: under elimination the
4623	condition-side copy is **solution-defining** and must agree with the world's,
4624	whereas under enlargement a handle can at most inform the initial guess —
4625	convergence-relevant, solution-irrelevant. The second axis is a rig-shape
4626	choice and never touches trim doctrine. **Residual risk, mitigation deferred to
4627	`pending.md`** (landed as [D-262][d-262]): under elimination a params-vs-world handle mismatch
4628	converges to a *true* equilibrium at an *unintended operating point* — the
4629	eliminated targets are never residual-checked, so nothing complains — and a
4630	cheap post-commit read-back of EAS/γ/β against the requested targets catches
4631	the whole class.
4632	
4633	**Rejected.**
4634	- *Widening the condition signature to `condition(d, baseline)` so the math
4635	  reads the handle out of the baseline:* single-sources the handle in a rig,
4636	  but is **rig-only** — in a full world the environment face is wired and
4637	  absent from the baseline, and serving it there would mean pre-sweeping the
4638	  environment subtree; it also makes every problem's meaning depend on the
4639	  baseline it is applied against — the hidden-input shape [§14.1][s14-1]'s overlay-base
4640	  decision kills, reintroduced one level up — and it breaks the pure condition
4641	  algebra that makes [§14.9][s14-9]'s `at`-lifting five lines.
4642	- *A pre-application or partial sweep making swept outputs readable at
4643	  condition time:* reaffirms [§14.2][s14-2]'s by-name rejection of init as a third
4644	  scheduled sweep, and deciding which subtree is state-independent and
4645	  therefore safe to pre-sweep is graph reasoning the services deliberately do
4646	  not do.
4647	- *Mandating enlargement as the sole route:* discards closed-form knowledge the
4648	  aircraft author has — the aero validity envelope is a box in (TAS, α, β) and
4649	  nothing like a box in Cartesian `v_eb_n`, so bounds either clip the feasible
4650	  set or admit excursions into table extrapolation, the practical source of
4651	  failed trims — where elimination keeps today's proven 7×7 shape.
4652	- *Reading the environment through `reads`:* circular — reads are gathered
4653	  after the sweep the condition precedes.
4654	- *Duplicating the atmosphere's `h_xu` in aircraft trim code:* the drift class
4655	  itself.
4656	
4657	Stated to forestall the reading: none of this reopens [D-008][d-008]'s rejected resource
4658	injection — no registry, no invisible composition, just a plain function call
4659	on values the caller already holds.

1986	### D-067 — Boundary zero runs the macro-sequence with an empty integrate
1987	
1988	**Status.** ratified
1989	
1990	**Position.** Boundary zero is the [§10.6][s10-6] macro-sequence run with an empty
1991	integrate: project → sweep (every tick due; discrete stages publish from the
1992	authored `z`) → events to quiescence → due `g` updates → header capture + first
1993	snapshot.
1994	
1995	- Interval alignment is a taught contract, sibling of [§8.6][s8-6]'s boundary-sampling
1996	  line: a boundary's update is the *outgoing* transition — `z_{k+1}` from
1997	  `t_k`'s samples — so boundary zero's incoming transitions on both tiers are
1998	  replaced by authorship, and the update at `t₀` is the `t₀` sample's only
1999	  chance.
2000	- `t₀` is an init-service argument anchoring the harmonic grid (conditions
2001	  time-free; `capture` returns condition and time separately).
2002	- Trim iterations bypass boundaries entirely — raw write→sweep→read on the
2003	  activation — and only the commit runs boundary zero, a guard firing at commit
2004	  replacing today's hand-written trim asserts.
2005

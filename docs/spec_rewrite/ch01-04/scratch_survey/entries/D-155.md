5498	### D-155 — Name projection as the second legitimate mover of the committed point
5499	
5500	**Status.** ratified
5501	
5502	**Position.** **Projection is named the second legitimate mover of the
5503	committed point** — boundary zero's first act makes the committed `x`
5504	`project(x*)`, not `x*` (a quaternion normalized by ulps), alongside the
5505	already-channeled commit-fired handlers — and the `TrimReport` carries both
5506	residual sets: the solved-point residuals ([D-150][d-150]'s verdict numbers, unchanged,
5507	gating the commit) and the **committed-state residuals, re-gathered from the
5508	boundary-zero world** (nearly free — boundary zero's sweep has already run —
5509	and they describe the state the simulation is actually in, the point
5510	`capture`-defaulted `linearize` reads); a converged solve whose committed-state
5511	residuals violate the box test raises the new service warning
5512	`TrimCommitResiduals` ([Appendix C][sC]: offending residual names, committed values,
5513	tolerances) — flag-when-it-occurs applied to the moved point.
5514	
5515	**Spec.** [§14.5][s14-5], [§14.8][s14-8], [Appendix C][sC]
5516	
5517	**Rationale.** A round-5 kernel dry-run finding (finding 11), upholding
5518	[D-149][d-149]/[D-150][d-150].
5519	
5520	**Rejected.**
5521	- *Reporting the solver's last evaluation only:* residuals belonging to a state
5522	  the simulation is not in; an out-of-tolerance commit invisible.
5523	- *Refusing or reverting the commit on post-commit violation:* the movers are
5524	  legitimate semantics — projection is ulps, events already flagged via
5525	  `TrimCommitEvents` — and refusal re-institutionalizes discarding converged
5526	  work against [D-149][d-149]'s grain.

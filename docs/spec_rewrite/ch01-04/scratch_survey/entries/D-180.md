6564	### D-180 — Bank per-event `direction` as an unbuilt guarded addition
6565	
6566	**Status.** ratified
6567	
6568	**Position.** Per-event `direction` (`:upward`/`:downward`/`:both`) is recorded
6569	as a guarded addition, unbuilt.
6570	
6571	**Spec.** [§2.1][s2-1]
6572	
6573	**Rationale.** `:downward` is pure sign-flip sugar (desugars to the negated
6574	predicate); `:both` (fire on any predicate change) costs little machinery —
6575	compile-folded edge test, direction-blind root-finder, endpoint policy
6576	generalizing to the post-edge endpoint — but serves only the shared-handler use
6577	case, and the domain's transitions are asymmetric-handler pairs ([D-082][d-082]:
6578	hysteresis wants two events anyway); strong precedent exists (MATLAB events
6579	`direction = 0`, Simulink either-direction zero-crossings, Modelica both-edge
6580	relation events), so it is banked until migration shows demand.
6581	
6582	**Rejected.**
6583	- *Building it now:* machinery cheap but no grounded use case; [§2.1][s2-1]'s
6584	  negated-guard second event covers every current need.
6585	- *Rejecting it permanently:* the precedent is universal and the analysis shows
6586	  no structural obstacle.

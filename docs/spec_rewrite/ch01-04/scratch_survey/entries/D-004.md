399	### D-004 — Immutable value signals in a typed signal table
400	
401	**Status.** ratified
402	
403	**Position.** Immutable value signals in a typed signal table.
404	
405	**Spec.** [§4.1][s4-1]
406	
407	**Rationale.** Recorded only through the rejections below.
408	
409	**Rejected.**
410	- *Shared mutable buffers:* aliasing/staleness, concurrent-read hazards.
411	- *Mixed semantics:* second thing to document/test.
412	- *A monolithic per-component `y` struct:* freshness is per-struct, so it can
413	  be half-fresh mid-sweep with no way for a reader to tell — per-cell freshness
414	  is tied to the producer's schedule position.

2746	### D-090 — Return handler updates as bundle-law NamedTuples
2747	
2748	**Status.** ratified
2749	
2750	**Position.** Handler returns are NamedTuples under the bundle law ([§5.2][s5-2],
2751	[§9.5][s9-5]): `(; x, m)`, a key present iff the store exists AND the handler updates
2752	it — a pure FSM returns `(; m = …)`, a reset map `(; x = …)`.
2753	
2754	**Spec.** [§5.2][s5-2], [§9.5][s9-5]
2755	
2756	**Rationale.** Checks per key: `x` present ⇒ complete against the state field
2757	set, `m` present ⇒ names-subset, unknown key ⇒ did-you-mean against `{x, m}`
2758	narrowed to the declared stores — the argument-side `FieldError` machinery run
2759	in both directions.
2760	
2761	**Rejected.**
2762	- *Positional pair `(x⁺, m⁺)`:* reintroduces the padding [D-074][d-074] bans on
2763	  arguments — `((;), m⁺)` / `(x⁺, (;))` for single-store components — and lets
2764	  the two stores swap with a diff-shaped rather than name-shaped error.

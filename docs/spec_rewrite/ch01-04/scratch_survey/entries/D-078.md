2386	### D-078 — Treat input entries as face constraints checked by subtyping
2387	
2388	**Status.** ratified
2389	
2390	**Position.** Input entries are face constraints: wiring check `producer_face
2391	<: entry` at nominal faces — one uniform rule, exact equality the concrete
2392	degenerate.
2393	
2394	**Spec.** [§4.4][s4-4], [§6.1][s6-1], [§8.2][s8-2], [§9.1][s9-1]
2395	
2396	**Rationale.** Abstract entries = structural substitutability ([§4.4][s4-4] field
2397	handles), never needed for eltype genericity (an eltype-generic producer's
2398	nominal face is concrete by construction); root-slot carve-out — only a tight
2399	(concrete) bound determines a producerless cell's type, abstract-at-root a
2400	build error; under fan-out the slot type is the unique concrete declaration
2401	among consumers, abstract co-consumers checked against it; doctrine:
2402	declarations record choices, obligations are checked.
2403	
2404	**Rejected.**
2405	- *Exact-equality-only status quo:* welds [§4.4][s4-4] consumers to one concrete
2406	  producer type, or leaks wiring facts into component type parameters —
2407	  `Strut{H}` cascading through every owning assembly.
2408	- *Symmetric `T` as genericity envelope:* a per-leaf marking that is a constant
2409	  function across components — zero information, wrong granularity,
2410	  false-affordance pins; the predictive reading remains impossible per [D-054][d-054].
2411	- *Phantom root producer with `output_types`-style slot declarations:*
2412	  re-enumerates what exports already are — [D-043][d-043]'s `add_input!` reborn;
2413	  two-artifact drift; root-ness is deployment, not type; its pin bit is policy
2414	  wearing a description's syntax — pinned ≡ unseeded to every derivative.

2505	### D-082 — Define guard conditions against a per-event baseline
2506	
2507	**Status.** ratified
2508	
2509	**Position.** Guard conditions and baselines: a guard defines a condition
2510	(`Bool` predicate, or continuous with positive = holding, `σ ≥ 0`); events fire
2511	on not-holding → holding edges against a per-event baseline held in loop state
2512	(previous boundary's quiescent sample, updated at quiescence — detection
2513	bookkeeping, not model memory: not in `z`, not captured, reconstructed on warm
2514	restart).
2515	
2516	**Spec.** [§10.4][s10-4], [§10.6][s10-6], [§14.5][s14-5]
2517	
2518	**Rationale.** Boundary-zero baseline = nothing-holds (authored guard-true
2519	conditions fire at `t₀`, [§14.5][s14-5] derived); opposite direction = second event with
2520	negated guard; localization returns the holding endpoint of the final bracket —
2521	`t* = tₙ` structurally impossible (left end strictly not-holding; published
2522	boundaries immutable), guard observably holds at `t*`, `t* = tₙ₊₁` degenerates
2523	to the grid boundary (Tier-1-coincident, one snapshot); grid times indexed,
2524	never accumulated (remainder step targets the grid point).
2525	
2526	Annotation (2026-10-02): refined by [D-274][d-274]. The prior is in no state store
2527	and no condition, and a re-run from a condition rebuilds it at boundary zero.
2528	Every checkpoint, the trace header included, carries it, and `restore!`
2529	copies it back.
2530	
2531	**Rejected.**
2532	- *Direction-agnostic sign-change firing:* no coherent boundary-zero behavior;
2533	  hysteresis wants two events anyway.
2534	- *Baseline in `z`:* detection policy leaking into model state, wrongly
2535	  captured and replayed.
2536	- *Level-triggered per-boundary firing:* sticky flags re-fire every boundary.
2537	- *Midpoint or not-holding-end `t*` return:* handler fires where its own
2538	  condition reads false; baseline records an assumption.
2539	- *Suppressing `t₀` firings:* [§14.5][s14-5]'s anti-diagnostic insurance.
2540	- *Accumulated time `t ← t* + h′`:* ulp drift into every tick comparison and
2541	  deadline.

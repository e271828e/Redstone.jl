7131	### D-195 — Give the discrete state its own letter `s`
7132	
7133	**Status.** ratified
7134	
7135	**Position.** The discrete state un-fuses from `x` into its own letter `s`;
7136	[D-173][d-173]'s `z` retirement stands untouched — bare `z` still means only the shift
7137	operator `z⁻¹`.
7138	
7139	- The discrete-tier names re-split: `h_x`/`h_xu` → `h_s`/`h_su`, `init_x` →
7140	  `init_s`, `y_x` → `y_s`, bundle field `x` → `s`, `x⁺ = g(x,u,t)` → `s⁺ =
7141	  g(s,u,t)`; the continuous tier keeps the `x` family, and `f`/`g`, `m` and
7142	  `Δt` keep their meanings.
7143	- The per-function-per-tier closed bundle-name sets become per-function closed
7144	  sets again: the two tiers' name families are disjoint by construction.
7145	- The wrong-letter error class [D-173][d-173] retired rejoins
7146	  `DeclarationOnWrongTier`'s member set — a discrete leaf declaring `h_x`, or
7147	  a continuous one declaring `h_s`, is statically diagnosable again.
7148	
7149	**Spec.** [§3.2][s3-2], [§5.2][s5-2], [§5.3][s5-3], [§7.3][s7-3], [§8.2][s8-2], [§8.7][s8-7], [§9.3][s9-3], [§9.5][s9-5], [§12.5][s12-5], [§13.7][s13-7], [§14.1][s14-1], [§3.4][s3-4], [§8.6][s8-6],
7150	[Appendix A][sA], [Appendix B][sB], [Appendix C][sC], [Appendix D][sD] (all companions swept)
7151	
7152	**Rationale.** [D-173][d-173] correctly retired `z` but recycled the continuous letter,
7153	erasing a real distinction: the discrete state is a different object — no
7154	derivative, any isbits type (pinned, eltype-generic or mixed), latched between
7155	ticks, stored in per-component state stores where the continuous state lives in
7156	the flat buffer ([§9.4][s9-4]) — and one letter made leaf declarations and framework
7157	prose read as one mechanism where the engine holds two.
7158	
7159	[D-173][d-173]'s "every candidate letter is taken" premise has since emptied for `s`:
7160	the Laplace variable appears nowhere in the spec — the document's only
7161	transform-domain symbol is `z⁻¹` — and `s` carries unique positive precedent,
7162	being legacy FlightCore's own discrete state field (`Model.s`), which [§12.5][s12-5]'s
7163	consumer survey already quotes as `x`/`s`; the migration (`migration_outline.md`) reads the legacy
7164	vocabulary back rather than introducing a third letter. The "doubled API"
7165	objection is nominal, not per-leaf: a leaf is strictly one tier ([D-056][d-056]) and
7166	still implements exactly one name family, and the doubling buys back the
7167	wrong-letter diagnostic. The hybrid-systems `x⁺` convention [D-173][d-173] leaned on
7168	models a single state that both flows and jumps; the framework's tiers are
7169	disjoint ([D-056][d-056], [§3.2][s3-2]), so its premise never applied here. [D-173][d-173]'s
7170	`is_discrete` rejection is untouched — the arity-is-the-tier doctrine survives
7171	with the letters split.
7172

7174	with its member of `DeclarationOnWrongTier`, and gives `y_state` and
7175	`y_direct` one legal name set per tier. The state-letter split stands.

7184	  the feedthrough matrix in `linearize`'s return, `d` the trim decision vector

7186	- *Keeping the fusion:* the collision argument that motivated it was against
7187	  `z`, not for `x` — with a clean letter available, the shared letter's only
7188	  remaining yield is the halved name count, which per-tier disjointness makes a
7189	  diagnostic asset instead.

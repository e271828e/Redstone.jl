683	### D-018 — Tier-2 event localization via dense output and bracketed root-finding
684	
685	**Status.** ratified

687	**Position.** Tier-2 localization: lazy cubic Hermite dense output + bracketed
688	derivative-free root-finding (ITP/Brent) on guard probes that run the sweep;

695	where [§10.6][s10-6]'s edge checks read it — a projection that undoes the crossing costs
696	one extra harmless boundary.

700	**Rationale.** Recorded only through the rejections below.

702	**Rejected.**

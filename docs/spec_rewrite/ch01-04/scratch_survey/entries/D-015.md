597	### D-015 — Fused evaluation of derivatives and outputs
598	
599	**Status.** ratified
600	
601	**Position.** Fused evaluation: `f`/`h` read the fresh table (own `y`
602	included), and additionally receive state views ([D-035][d-035]); single computation
603	site for derivatives and outputs is the *rewarded* idiom, not an impossibility
604	claim.
605	
606	**Spec.** [§5.3][s5-3], [§7.4][s7-4], [§10.5][s10-5]
607	
608	**Rationale.** Recorded only through the rejections below.
609	
610	**Rejected.**
611	- *Mutable caches between `f` and outputs:* S-function/FMI style — hidden
612	  state, purity violation.
613	- *Accepting duplicate computation:* drift bug class — edited law in `f`, stale
614	  copy in `g`.
615	- *Derivative binding:* a declaration feature subsumed by `y`-access.
616	- *Orthodox `f(x,u)` + atomization as standard idiom:* 2× components/wiring for
617	  the domain-normal overlap case.

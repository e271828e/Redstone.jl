1398	### D-045 — Periphery input semantics: derived liveness, conditioning, mappings, edge logic
1399	
1400	**Status.** ratified
1401	
1402	**Position.** Periphery input semantics are settled on five points — liveness,
1403	conditioning, mappings, edge logic and pokeability:
1404	
1405	- GUI liveness is fully derived: transitive root-slot resolution ∧ slot
1406	  unclaimed.
1407	- Faces carry writer-independent post-conditioning semantics, the GUI-parity
1408	  test.
1409	- Mappings are declarative binding data with per-axis conditioning params,
1410	  living on the device task.
1411	- Edge logic is staged counters plus model-state accumulators.
1412	- Unexported ports are unpokeable.
1413	
1414	**Spec.** [§11.7][s11-7]
1415	
1416	**Rationale.** Recorded only through the rejections below.
1417	
1418	**Rejected.**
1419	- *Per-port "GUI-controlled" markings:* the export chain is the marking, owned
1420	  by the right author.
1421	- *Nominally-connected + GUI override channel:* second write path; breaks frame
1422	  purity and trace; done right it collapses into root slots.
1423	- *Conditioning in-model:* fails GUI-parity — sliders and scripts would be
1424	  deadzoned.
1425	- *Shaping as per-device mapping code:* aircraft semantics duplicated per
1426	  device — today's demonstrated smell.
1427	- *Joystick-as-component and root-level `PilotInterface`* (`flight_case_studies.md`): replay
1428	  same-build, single audit point, no natural home in `World`. Annotation (from
1429	  the C172X case study's inline treatment, migrated): devices-as-components also duplicates
1430	  [§12.4][s12-4]'s device lifecycle in component vocabulary and costs the drain its
1431	  standing as the single audit point for external data, while the GUI stays
1432	  irreducibly a staging device so inbound uniformity is unreachable either way
1433	  — and the rejection rests on these invariants, not on [§12.5][s12-5]'s clock
1434	  criterion, the scheme being internally consistent in an interactive paced
1435	  world.
1436	- **Bundled command faces** (`pilot_inputs` as one struct port): kills
1437	  per-field claiming, liveness and trace tag — the port is the
1438	  periphery's atomic unit on the write side too, [§4.3][s4-3] — and the routing
1439	  convenience it bought under argument threading is the namespace prefix plus
1440	  `input_passthrough` here.

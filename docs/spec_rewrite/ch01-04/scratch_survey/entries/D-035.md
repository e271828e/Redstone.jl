1132	### D-035 — Stores and views: components read zero-copy view bundles
1133	
1134	**Status.** ratified
1135	
1136	**Position.** Stores and views: every component function receives zero-copy
1137	views of the stores it genuinely reads — `h_xu`, `f`, `h_zu`, `g`, guards and
1138	handlers alike — arriving as one named bundle destructured in the signature
1139	([D-074][d-074]); the table holds produced signals only, never transported ones (one
1140	home per datum); selective auto-publication of declared state/mode fields;
1141	`h_x`/`h_z` = the no-feedthrough stage.
1142	
1143	**Spec.** [§5.2][s5-2], [§5.3][s5-3], [§7.1][s7-1], [§7.4][s7-4]
1144	
1145	**Rationale.** Recorded only through the rejections below.
1146	
1147	Annotation (2026-10-02): amended by [D-252][d-252], which removes auto-publication. A
1148	component exposes a state or mode field by returning it from `y_state`. The
1149	views, the bundle, the produced-only table and the no-feedthrough stage stand.
1150	[D-252][d-252]'s `output_state` is `y_state` since [D-267][d-267].

1152	**Rejected.**
1153	- *Superseded position — state-free evaluation prototypes with identity
1154	  transport (the earlier design of record, [D-015][d-015]/[D-016][d-016] as argued):* the
1155	  "published anyway" camouflage fell with contract visibility, and the
1156	  drift-unwritability claim was overstated — `f` always had `u` plus published
1157	  state.
1158	- *Packing `u` into the stage-2 product / `f(comp, y, t)`:* the reductio —
1159	  republishing foreign cells under local names.
1160	- *Transition-functions-only middle position:* fixes handlers but keeps hidden
1161	  state transport for `f`/`h`.
1162	- *State cells mirroring the buffer:* dead stores — no own-function reader
1163	  remains.

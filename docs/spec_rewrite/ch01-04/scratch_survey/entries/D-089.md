2720	### D-089 — Route supervisor gains and resets through ordinary ports
2721	
2722	**Status.** ratified
2723	
2724	**Position.** Supervisor idioms ([§5.3][s5-3]): scheduled gains are input ports —
2725	scheduler components own lookup tables as inert parameters and publish
2726	per-compensator gain bundles (gain trajectories observable in log/trace/replay,
2727	dependency visible to the feedthrough graph, linearization holds unseeded gains
2728	constant).
2729	
2730	**Spec.** [§5.3][s5-3], [Appendix A][sA]
2731	
2732	**Rationale.** One-shot design-time gains = construction-time parameters or
2733	stopped-sim service outputs; commanded resets are same-tick inputs consumed in
2734	the *output stage* with `g` storing the matching `z⁺` ([Appendix A][sA] entry; reset
2735	honored only in `g` = one-tick-late outputs, legal where that is meant).
2736	
2737	**Rejected.**
2738	- *Writable parameter store / `Ref`-mutable component parameters:* invisible to
2739	  log, trace, replay and the feedthrough graph — [D-031][d-031]'s raw-poke rejection
2740	  applied to parameters; breaks immutable component structs.
2741	- *A framework reset capability:* ordinary ports suffice — a second mechanism.
2742	- *Reset-in-`g`-only as the idiom:* publishes the stale command at the
2743	  engagement tick — the bump bumpless transfer removes; [§10.6][s10-6]'s `z⁻¹` discipline
2744	  makes the output stage the only same-tick path, [D-067][d-067].

805	### D-022 — Periphery architecture: no shared mutable model
806	
807	**Status.** ratified
808	
809	**Position.** Periphery architecture: no shared mutable model — staged inputs
810	drained at frame top + immutable snapshot published per boundary; every handoff
811	one atomic reference op, GC as reclamation; no user code or unbounded work in
812	framework critical sections; control on a separate atomic surface (staging
813	cannot un-pause a drainless loop); interactive = batch + devices.
814	
815	**Spec.** [§11.1][s11-1]
816	
817	**Rationale.** Recorded only through the rejections below.
818	
819	**Rejected.**
820	- *Transplanted `io_lock`:* loop budget hostage to arbitrary code under the
821	  lock; input timing scheduler-determined and unrecorded — replay undefinable
822	  in principle; protects a live-mutation idiom the immutable table removed.
823	- *Full message-passing periphery:* per-device typed channels — same design
824	  with heavier ceremony.

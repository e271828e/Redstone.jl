9198	### D-243 — Classify `Symbol` as an opaque port leaf
9199	
9200	**Status.** ratified
9201	
9202	**Position.** The port walk treats a `Symbol` as one opaque leaf: stored
9203	whole in a cell of its own eltype, accepted by identity, never descended.
9204	Julia's `ismutabletype(Symbol)` does not make it a mutable type for [D-237][d-237]'s
9205	refusal. A `Symbol` surfacing as a root input is refused like a handle, since
9206	it has no synthesis.
9207	
9208	**Spec.** [§4.3][s4-3], [§7.3][s7-3], [Appendix C][sC]
9209	
9210	**Rationale.** [§4.1][s4-1] requires of a port value immutability plus frozen
9211	references, and [§7.3][s7-3] admits a `Symbol` in a store because it is interned,
9212	immutable and never freed. A `Symbol` therefore meets the table's requirement
9213	on the grounds the store already accepts. [D-237][d-237] refuses mutable types to rule
9214	out aliasing, and no API mutates a `Symbol`; the refusal the walk raised was
9215	an artifact of Julia's classification, not of the design's reasoning. The
9216	cost of the refusal was concrete: the idiomatic mode label is a `Symbol`, so a
9217	mode so labelled could not be declared public, and [§7.5][s7-5]'s remedy for the
9218	absent event stream worked for enum modes alone. The classification is by
9219	[D-237][d-237]'s existing rule with one exemption, so the store shape, the identity
9220	acceptance and the outermost-type rule all carry unchanged. A struct nesting
9221	a `Symbol` is non-isbits and immutable, hence one opaque leaf as a whole,
9222	which mirrors [§7.3][s7-3]'s ruling that a struct nesting a `Symbol` is not a store
9223	field. A `Symbol` root input has no first instance and no zero, so the
9224	handle's refusal covers it.
9225	
9226	**Rejected.**
9227	- *Keeping the refusal and making `Symbol` store-only:* the argument that
9228	  admits it at the store is denied at the table, and [§7.5][s7-5]'s remedy stays
9229	  halved.
9230	- *A scalar-like leaf with `Symbol("")` as its synthesis:* a meaningless
9231	  default the probe would feed to a stage; the empty symbol is no instance an
9232	  author means.

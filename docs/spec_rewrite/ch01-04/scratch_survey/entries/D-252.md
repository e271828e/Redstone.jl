9661	### D-252 — Remove auto-publishing: two port classes, exposed state returned by stage 1
9662	
9663	**Status.** ratified
9664	
9665	**Position.** A declared output is produced by stage 1 or by stage 2, and by
9666	nothing else. A component exposes a state or mode field by returning it from
9667	`output_state`. A declared output that no stage produces is
9668	`DeclaredNotProduced`, everywhere and at every tier. `ProducedByTwoStages`
9669	carries the component path and the port name; the two stages are the kind's
9670	own, so the producer column goes with the third class. Supersedes [D-016][d-016]'s
9671	publication rule, [D-152][d-152]'s successor in [D-154][d-154]'s sequence, and [D-169][d-169].
9672	
9673	**Spec.** [§5.2][s5-2], [§5.3][s5-3], [§7.1][s7-1], [§7.5][s7-5], [§8.3][s8-3],
9674	[§9.1][s9-1], [§9.3][s9-3], [§10.6][s10-6], [§13.2][s13-2], [Appendix B][sB],
9675	[Appendix C][sC], [Appendix D][sD]
9676	
9677	**Rationale.** Auto-publishing was a third port class the framework wrote.
9678	It cost more than the line it saved. Stage 1's hand-down had to exclude the
9679	published names ([D-169][d-169]), the classifier probed by name and type and silently
9680	un-published a name held at another type, the executor grew a
9681	`PublishEntry` beside the stage entries, the published set threaded through
9682	every stratum and into `compile`'s key slicing, and a `ConformanceFailure`
9683	arm existed only to refuse a `Float64`-pinned declaration of a walking field
9684	at the `Dual` activation. Each piece was correct and each was there for one
9685	convenience: not writing `output_state(c, (; x)) = (; q = x.q)`. The
9686	2026-09-18 probe over the suite found nine of seventy-eight fixture
9687	components relying on publication, six of them written to test it. The
9688	remaining refusal already exists: `DeclaredNotProduced` names the declared
9689	port, the stage products and the store fields, and its remedy becomes
9690	"return it from `output_state`". With one writer per port the port model is
9691	homogeneous, the `Dataflow` artifact ([D-253][d-253]) classifies by return alone, and
9692	the trace and status surfaces stop distinguishing a framework write from a
9693	stage write.
9694	
9695	**Rejected.**
9696	- *Keeping publication as it stood:* the machinery above, for one line per
9697	  exposed field.
9698	- *Opt-in publication sugar (a declaration listing fields to expose):* a
9699	  second way to write `output_state`'s return, with the same classification
9700	  seam.
9701	- *A dev-mode flag publishing every state field ([§11.7][s11-7]'s note):* still
9702	  possible as a debugging aid, but it would be a reader over the stores, not
9703	  a port class; it is recorded, not built.
9704	- *Refusing only at the root:* an unproduced port inside an assembly is the
9705	  same silent zero, one level down.

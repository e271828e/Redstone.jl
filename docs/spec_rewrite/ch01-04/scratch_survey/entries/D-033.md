1055	### D-033 — Declaration inventory: by-value, by-type, by-allocation conventions
1056	
1057	**Status.** ratified
1058	
1059	**Position.** Declaration inventory: `init_*` by value (type derived — nothing
1060	to drift); `input_types(::C)` bare NamedTuple of types at `Float64` faces,
1061	wiring check `producer_face <: entry` ([D-078][d-078]);
1062	`output_types(::C)`/`local_types(::C)` plain concrete nominal declarations on
1063	both tiers, per-activation cell types from the framework leaf walk ([D-079][d-079]);
1064	`workspace` registered by allocation ([D-077][d-077]); `events(::C)` ordered + per-event
1065	`localize` flag (`true` = Tier 2, default `false` = Tier 1); stage membership
1066	derived (inputless `h_x` probes first, remainder is stage 2), no stage tags.
1067	
1068	**Spec.** [§4.2][s4-2], [§7.1][s7-1], [§8.1][s8-1], [§8.2][s8-2]
1069	
1070	**Rationale.** The inventory is self-classifying by convention: by value
1071	`init_*`, by type `*_types`, by allocation `workspace` ([D-076][d-076]). Contract
1072	declarations are functions of the component's *type*, parameters included
1073	(`SumJunction{W,N}`, `Or{N}`), never of field values — `workspace` explicitly
1074	exempt (by-allocation, [D-077][d-077]) — because [§9.7][s9-7]'s entry typing derives the bundle
1075	key set from the type; a rule authors keep, not a check the build can run
1076	([§8.1][s8-1]).
1077	
1078	Annotation (2026-10-02): amended by [D-165][d-165] and [D-179][d-179]. `local_types` is deleted,
1079	and an event carries no `localize` flag, since the guard's return type declares
1080	its detection policy. The three declaration conventions and derived stage
1081	membership stand.
1082	
1083	**Rejected.**
1084	- *Superseded position — `outputs(::C, ::Type{T})` on continuous components
1085	  with plain `outputs(::C)` on discrete as the tier-in-signature marker (the
1086	  earlier design of record):* functions of the sweep scalar, literal `Float64`
1087	  = deliberate non-participation; retired with the `T`-signature ([D-079][d-079]).
1088	- *Exact-equality wiring check:* relaxed to subtype, equality the concrete
1089	  degenerate ([D-078][d-078]).
1090	- *The names `inputs`/`outputs`/`locals`:* renamed for self-classification by
1091	  convention and to dissolve the `inputs` vs `input_faces` ambiguity
1092	  ([D-076][d-076]).
1093	- *Under-the-hood `Float64→T` substitution:* reflection-heavy; cannot
1094	  distinguish honest `Float64`s.
1095	- *Sentinel eltype tokens:* same machinery, worse spelling.
1096	- *Subtype/pattern matching on the output side:* motivating case dissolved by
1097	  `T`; abstract slots break concrete typing.
1098	- *Names-only input contracts:* lose wiring-time type errors and standalone
1099	  checkability.
1100	- *Per-stage output lists:* stage membership is internal, [§4.2][s4-2].

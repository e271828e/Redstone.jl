5447	### D-154 — Remove per-event re-decode; serialize same-component events
5448	
5449	**Status.** ratified
5450	
5451	**Position.** **The per-event re-decode is removed — the signal table is
5452	written only by sweeps — and a component fires at most one event per round**,
5453	declaration order picking among its simultaneously-eligible events (guards stay
5454	evaluated every round for [D-153][d-153]'s samples; the firing step is what's capped;
5455	once-per-event-per-boundary and the quiescence iteration unchanged, so
5456	multi-event components keep full within-boundary expressiveness, serialized
5457	across rounds). The single epoch rule follows: **a handler executes against
5458	exactly the world its guard fired on** — own `y`, foreign `u` and own `x`/`m`
5459	are all the firing round's sweep, so `y = h(x)` holds at every handler entry
5460	(f.5's incoherence dissolved by deletion where [D-152][d-152] dissolved it by addition),
5461	a blocked event is re-decided next round against the post-transition sweep
5462	(fire-on-falsified-premise gone), and cross-component handler order is
5463	unobservable with no delivering mechanism (nothing writes mid-round).
5464	
5465	**Spec.** [§5.3][s5-3], [§10.4][s10-4], [§10.6][s10-6]
5466	
5467	**Rationale.** A round-5 kernel dry-run finding (finding 10), resolved by
5468	redesign after re-examining the within-round visibility rule it implements —
5469	supersedes [D-016][d-016]'s per-event re-decode, its [D-152][d-152] auto-publish amendment, and
5470	[D-100][d-100]'s pre-materialization mechanism ([D-100][d-100]'s round-start-`u` *semantics*
5471	survives, now by construction). The natural single-pass executor is correct:
5472	f.10's staging pass, carrier and `u`/`y` split are mooted and "no shadow table,
5473	no allocation" becomes trivially true; cost = one extra intra-boundary sweep
5474	per serialized same-component event, rare and microseconds.

638	**Rejected.**
639	- *Superseded position — identity publication of state and modes as the
640	  default, plus an unlisted-port convention for interface noise (the earlier
641	  design of record):* retired because contract visibility ([D-034][d-034]) makes
642	  publicity a declaration, and `unlisted` pretended privacy without enforcing
643	  it (hidden but connectable).
644	- *Passing state alongside `y`:* double-passing; two idioms in the wild.
645	- *Fully private discrete state:* breaks uniformity; the codebase culturally
646	  publishes state anyway.
647	- *One-handler-per-component-per-boundary restriction:* the cheap per-event
648	  re-decode removes the need.
649	- *Exposing `z` without an unlisted convention:* RNG/log noise.
650	- *The `unlisted` motivating case — RNG state feeding the component's own
651	  update:* dissolved entirely once [D-035][d-035] gave every function direct `x` views,
652	  so nothing needed publishing to be readable.

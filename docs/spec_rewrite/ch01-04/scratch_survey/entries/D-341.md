14026	### D-341 — The bundle law, the closed name sets and per-key return checks
14027	
14028	**Status.** ratified
14029	
14030	**Position.** Seven hand-off rulings that [§5.2][s5-2] states are fixed here.
14031	
14032	- A bundle field is present iff its store or fact exists for the component.
14033	  An undeclared store is absent, never `nothing`-filled. `t` is always
14034	  present, `Δt` only on the discrete tier, and `ws` iff `ws_init` is
14035	  declared.
14036	- Each function's legal name set is closed, one set per function per tier,
14037	  and growing a set takes a log entry.
14038	- A failed destructuring is diagnosed from the structured `FieldError`
14039	  matched against the bundle's own NamedTuple type, with did-you-mean against
14040	  the legal set. No message text is scraped, the bundle stays a bare
14041	  NamedTuple, and a getproperty wrapper is the recorded fallback.
14042	- The legal set narrows in three levels: stage name at its tier ⊇ bundle ⊇
14043	  destructured reads.
14044	- Positional signatures, keyword arguments read by `Base.kwarg_decl`
14045	  reflection and keyword slurping are closed spellings. So is padding an
14046	  undeclared store with `nothing` or `(;)`, in arguments and handler returns
14047	  alike.
14048	- A handler return is checked per key, the argument side's `FieldError`
14049	  machinery run in both directions. A present `m` passes the names-subset
14050	  predicate.
14051	- No component declares its dependencies. There are no per-output dependency
14052	  annotations.
14053	
14054	**Spec.** [§5.2][s5-2]
14055	
14056	**Rationale.** Each bullet restates what an existing entry recorded outside
14057	its Position. The bundle law, the closed name sets and the `FieldError`
14058	mechanism were recorded in [D-074][d-074]'s Rationale, and the per-tier sets in
14059	[D-220][d-220]'s. The three-level narrowing was recorded in [D-075][d-075]'s Rationale. The
14060	closed spellings and the argument padding were recorded in [D-074][d-074]'s Rejected
14061	list, and the handler-return padding in [D-090][d-090]'s. The per-key checks were
14062	recorded in [D-090][d-090]'s and [D-287][d-287]'s Rationales. The absence of dependency
14063	annotations was recorded in [D-006][d-006]'s Rejected list.
14064	
14065	**Rejected.** None beyond the source entries' lists.

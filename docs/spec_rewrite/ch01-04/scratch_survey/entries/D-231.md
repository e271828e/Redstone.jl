8685	### D-231 — Require isbits store values, checked at build
8686	
8687	**Status.** ratified
8688	
8689	**Position.** Every field of a store value — a discrete leaf's `s`, and any
8690	leaf's `m` — is isbits or a `Symbol`, and Stratum A checks every
8691	`init_s`/`init_m` field, reporting `IllegalStoreField`. The frozen-reference
8692	latitude of [§4.1][s4-1] stays with signals. A PRNG object is workspace; the values
8693	that determine its next draw are the state.
8694	
8695	**Spec.** [§3.2][s3-2], [§7.3][s7-3], [§8.2][s8-2], [§9.1][s9-1], [Appendix C][sC], [Appendix D][sD]
8696	
8697	**Rationale.** The three sources disagreed and the code checked nothing:
8698	[§7.3][s7-3] granted `s` "any immutable value" under the frozen-reference rule, the
8699	declaration's docstring and [D-195][d-195] said isbits, and the build enforced neither.
8700	Isbits is one exact predicate, `isbitstype`, checkable once at build.
8701	"Immutable plus frozen references" is a claim about the run and can only be
8702	contract, which contradicts [§7.3][s7-3]'s own opening — stores governed by checks,
8703	the workspace by contract. Every discrete-state use in the grounding is
8704	counters, enums, filter taps, timers and RNG words. The latitude was earned by
8705	field handles on ports ([§4.4][s4-4]), and bulk data does not change between ticks, so
8706	its home is the component instance. Isbits makes "snapshots are free" literal,
8707	gives a future on-disk trace one fixed layout per store, and retires the
8708	`deepcopy` hedges the implementation had placed around store capture and
8709	replay. The RNG example never needed type freedom: the generator is mutable
8710	and could never be a store value, and its state values are isbits. Measured on
8711	Julia 1.12, rematerializing a `Xoshiro` from its values each tick allocates
8712	under `randn`, whose out-of-line tail lets the object escape, and not under
8713	`rand`; a workspace-resident generator loaded by field assignment allocates
8714	under neither. The spec blesses the latter and stays silent on the generator's
8715	internals, which are the stdlib's. `Symbol` is admitted because it is not
8716	isbits in Julia yet loses nothing the rule was written for: interned,
8717	immutable and never freed, it copies as a pointer to permanent data, reads
8718	safely from any thread and serializes as its name. It is also how Julia code
8719	writes a label, where `@enum` puts every instance name into the module
8720	namespace, a cost that compounds across a component library. The check stays
8721	one exact predicate per field and does not recurse, so a struct nesting a
8722	`Symbol` is rejected.
8723	
8724	Annotation (2026-10-02): `m` is continuous-only, since a discrete component
8725	has no mode store ([§3.2][s3-2], [§8.2][s8-2]). "Any leaf's `m`" reads "the `m` of every leaf
8726	that declares one". `init_s` and `init_m` are `s_init` and `m_init` ([D-267][d-267]),
8727	and Stratum A is the structure step ([D-259][d-259]).
8728	
8729	**Rejected.**
8730	- *Any immutable value under the frozen-reference rule (the prior [§7.3][s7-3] text):*
8731	  uncheckable, so contract-only; motivated by an example that does not need
8732	  it; leaves the copy hedges in place.
8733	- *Isbits as contract, without a check:* the predicate is exact and one line;
8734	  a rule that can be checked and is not is the workspace's regime applied to
8735	  state.
8736	- *Rematerializing the generator per tick:* allocation depends on which
8737	  sampler is called, a property no spec should lean on.
8738	- *Naming the generator's word count in the spec:* stdlib internals; the
8739	  principle — mutable object in `ws`, its state values in `s` — survives a
8740	  field added or removed.
8741	- *Strict isbits, modes as enums:* the spec's own examples say enums and
8742	  would have needed no change, but the rule would forbid the `Symbol` idiom
8743	  for every author to buy a "self-contained bytes" claim nothing yet consumes.

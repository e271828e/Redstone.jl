842	### D-024 — Inbound staging: per-device atomic batch cells
843	
844	**Status.** ratified
845	
846	**Position.** Inbound staging: one atomic batch cell per device; complete
847	writers overwrite, sparse writers CAS-merge own cell (retry bounded by drain
848	interception); drain by `atomicswap` in attachment order; conflicts resolved by
849	slot exclusivity ([D-044][d-044]); levels-never-deltas doctrine; mappings pure, on the
850	device task; device-tagged replayable input trace.
851	
852	**Spec.** [§11.4][s11-4]
853	
854	**Rationale.** Recorded only through the rejections below.
855	
856	**Rejected.**
857	- *Superseded position — attachment order as the cross-device conflict
858	  precedence policy (the earlier design of record):* superseded by slot
859	  exclusivity, which removes the conflict instead of ranking it (the per-device
860	  cells, CAS merge and drain are retained for atomicity and coalescing).
861	- *Per-slot cells:* conflicts by hardware store order — run-to-run behavioral
862	  variance; cross-device peek; no trace tag; atomic-width fallback on
863	  wide slots.
864	- *Shared batch stack:* temporal conflict order; unbounded pending under pause,
865	  taxing peeks.
866	- *Ordered write queue:* preserves intra-frame order nothing downstream can
867	  observe.

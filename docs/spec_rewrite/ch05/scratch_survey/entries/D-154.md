5404	### D-154 — Remove per-event re-decode; serialize same-component events
5405	
5406	**Status.** ratified
5407	
5408	**Position.** **The per-event re-decode is removed — the signal table is
5409	written only by sweeps — and a component fires at most one event per round**,
5410	declaration order picking among its simultaneously-eligible events (guards stay
5411	evaluated every round for [D-153][d-153]'s samples; the firing step is what's capped;
5412	once-per-event-per-boundary and the quiescence iteration unchanged, so
5413	multi-event components keep full within-boundary expressiveness, serialized
5414	across rounds). The single epoch rule follows: **a handler executes against
5415	exactly the world its guard fired on** — own `y`, foreign `u` and own `x`/`m`
5416	are all the firing round's sweep, so `y = h(x)` holds at every handler entry
5417	(f.5's incoherence dissolved by deletion where [D-152][d-152] dissolved it by addition),
5418	a blocked event is re-decided next round against the post-transition sweep
5419	(fire-on-falsified-premise gone), and cross-component handler order is
5420	unobservable with no delivering mechanism (nothing writes mid-round).
5421	
5422	**Spec.** [§5.3][s5-3], [§10.4][s10-4], [§10.6][s10-6]
5423	
5424	**Rationale.** A round-5 kernel dry-run finding (finding 10), resolved by
5425	redesign after re-examining the within-round visibility rule it implements —
5426	supersedes [D-016][d-016]'s per-event re-decode, its [D-152][d-152] auto-publish amendment, and
5427	[D-100][d-100]'s pre-materialization mechanism ([D-100][d-100]'s round-start-`u` *semantics*
5428	survives, now by construction). The natural single-pass executor is correct:
5429	f.10's staging pass, carrier and `u`/`y` split are mooted and "no shadow table,
5430	no allocation" becomes trivially true; cost = one extra intra-boundary sweep
5431	per serialized same-component event, rare and microseconds.
5432

5434	replaced by `firing_budget`. One event per component per round and the epoch
5435	rule stand.

2249	### D-075 — Name flow/update/output stages by letter and dependence class
2250	
2251	**Status.** ratified
2252	
2253	**Position.** Letters and stage names: `f` = continuous flow, `g` = discrete
2254	update, `h_x`/`h_xu` (continuous) and `h_z`/`h_zu` (discrete) = output stages
2255	with products `y_x`/`y_xu`/`y_z`/`y_zu` — the hybrid-systems flow/jump pair
2256	(Goebel–Sanfelice–Teel) joined to the control/estimation `y = h(x, u)`
2257	convention.
2258	
2259	**Spec.** [§5.3][s5-3]
2260	
2261	**Rationale.** Bare `h` = step size only (double booking retired); suffix = the
2262	*dependence class* (state-only vs state-plus-input — `y = h(x)` vs `y = h(x,
2263	u)` in the name; modes fold under the state letter, ambient `t`/`Δt`/`ws`
2264	unnamed); the tier pairs mirror exactly (`x`/`xu` ↔ `z`/`zu`); declaration on
2265	the wrong tier = build error (`DeclarationOnWrongTier` — widened from stage
2266	names to all tier markers, `events` included, [D-112][d-112]); three-level narrowing
2267	taught (stage name ⊇ bundle ⊇ destructured reads).
2268	
2269	**Rejected.**
2270	- *`h` for the discrete update:* collides with the step size; forfeits the
2271	  jump-map alignment.
2272	- *`g` for outputs:* the complementary collision.
2273	- *`h_xm`/`h_xmu` letter-exhaustive suffixes:* traded for tier symmetry and the
2274	  textbook mirror — the suffix's job is the feedthrough split, not an argument
2275	  inventory.
2276	- *Verb names (`decode`/`compute`):* encode nothing.
2277	- *`Moore`/`Mealy`:* exact, opaque.
2278	- *A tier-neutral stage pair:* no honest neutral state letter; tier-distinct
2279	  names double as cheap drift checks. Superseded on this point by [D-173][d-173] —
2280	  fusing the discrete state into `x` supplies the honest neutral state letter
2281	  whose absence was the rejection's whole ground, and the drift-check value
2282	  dies with the distinction it policed.
2283	- *The earlier `g_s1`/`g_s2` stage spelling:* numbered stages name a schedule
2284	  position, not a dependence class, and leave `h` double-booked.

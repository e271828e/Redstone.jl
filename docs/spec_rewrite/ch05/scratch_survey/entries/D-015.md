591	### D-015 — Fused evaluation of derivatives and outputs
592	
593	**Status.** ratified
594	
595	**Position.** Fused evaluation: `f`/`h` read the fresh table (own `y`
596	included), and additionally receive state views ([D-035][d-035]); single computation
597	site for derivatives and outputs is the *rewarded* idiom, not an impossibility
598	claim.
599	
600	**Spec.** [§5.3][s5-3], [§7.4][s7-4], [§10.5][s10-5]
601	
602	**Rationale.** Recorded only through the rejections below.
603	
604	**Rejected.**
605	- *Mutable caches between `f` and outputs:* S-function/FMI style — hidden
606	  state, purity violation.
607	- *Accepting duplicate computation:* drift bug class — edited law in `f`, stale
608	  copy in `g`.
609	- *Derivative binding:* a declaration feature subsumed by `y`-access.
610	- *Orthodox `f(x,u)` + atomization as standard idiom:* 2× components/wiring for
611	  the domain-normal overlap case.

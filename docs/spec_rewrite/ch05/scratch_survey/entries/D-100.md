2990	### D-100 — Freeze `u` at round start for within-round event visibility
2991	
2992	**Status.** ratified
2993	
2994	**Position.** Within-round event visibility: handler-phase `u` gathers
2995	materialize at round start — after guard evaluation, before any handler runs —
2996	and the per-event re-decode reuses that round-start `u`; `y` binds live (own
2997	cells only, disjoint from `u`'s foreign set), so same-component successors see
2998	refreshed own ports (handler returns latch per-event) while foreign transitions
2999	arrive only through the next round's re-sweep.
3000	
3001	**Spec.** [§5.3][s5-3], [§10.6][s10-6], [§11.2][s11-2], [§13.4][s13-4]
3002	
3003	**Rationale.** Immutable cell values make early reference-loading a zero-copy,
3004	zero-allocation capture ([§11.2][s11-2]'s publication trick applied within a boundary);
3005	cross-component handler order is thereby semantically unobservable and is fixed
3006	(executor component order, declaration order within a component) only for [§13.4][s13-4]
3007	cursor/diagnostic determinism; `u` binds round-start uniformly, the own-wired
3008	corner included.

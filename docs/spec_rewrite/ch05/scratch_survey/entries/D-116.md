3527	### D-116 — Expose `phase_bodies(sim)` as the zero-allocation invariant's measurement seam
3528	
3529	**Status.** ratified
3530	
3531	**Position.** The zero-allocation invariant's measurement seam:
3532	`phase_bodies(sim)` returns the compiled bodies of the nominal activation as
3533	named callables bound over the simulation's own buffers — the four blocks
3534	(`rhs`, `sweep_hx`, `sweep_hxu`, `ticks` taking the tick index its entries gate
3535	on) plus per-event guards/handlers and per-component `project`, keyed by the
3536	model's roster; one inspection promise: identity with the bodies the
3537	loop runs, so the in-loop argument types come by construction; CI is
3538	warm-then-assert at per-body granularity (a documented tolerance loosens
3539	exactly one assertion).
3540	
3541	**Spec.** [§7.5][s7-5], [§9.7][s9-7], [Appendix B][sB]
3542	
3543	**Rationale.** [§7.5][s7-5]'s tiers completed: guards and `project` (unconditional per
3544	boundary/frame) join the exactly-zero tier, handlers (episodic, only on firing)
3545	join the tick tier's zero-by-idiom; publication is not a phase body — the [§7.5][s7-5]
3546	carve-out made structural; isolated invocation leaves buffers valid but
3547	off-trajectory (re-`init!` to continue); the FlightCore allocation comparison in `migration_outline.md`
3548	measures through the seam.
3549	
3550	Annotation (2026-10-02): [§7.5][s7-5] calls its tiers budgets. The "carve-out" is the
3551	invariant's scope, which [§7.5][s7-5] states: the invariant covers the stepping loop
3552	([D-305][d-305]), and publication is not a phase body ([D-288][d-288]). `project` is `x_projection`
3553	([D-220][d-220], [D-267][d-267]).
3554	
3555	**Rejected.**
3556	- *Per-body exported functions (`rhs!(sim)`, `guard!(sim, path, name)`, …):*
3557	  five-plus exported names, an invented addressing mini-language for the
3558	  per-event callables, and hand-enumerated CI lists that go stale when a model
3559	  gains an event, where the accessor's roster is machine-enumerable.
3560	- *A no-publish advance mode on `step!`:* forks execution semantics for CI's
3561	  benefit and breaks [§10.1][s10-1]'s publication-after-every-boundary property.
3562	- *`@allocated step!` against a pinned nonzero baseline:* drifts with every
3563	  model edit, and a regression can hide inside a legitimate baseline change —
3564	  kills the canary.
3565	- *Per-component standalone tests as the invariant's discharge:* they never
3566	  call the executor, so "framework contribution exactly zero" goes unvalidated;
3567	  hand-built argument types are not the in-loop types inference sees;
3568	  composition-scale pathologies — union-splitting collapse, chunk-seam
3569	  mis-specialization — are invisible; remains a fine authoring practice for
3570	  localizing once the canary trips.

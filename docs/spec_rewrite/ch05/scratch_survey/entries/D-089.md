2686	### D-089 — Route supervisor gains and resets through ordinary ports
2687	
2688	**Status.** ratified
2689	
2690	**Position.** Supervisor idioms ([§5.3][s5-3]): scheduled gains are input ports —
2691	scheduler components own lookup tables as inert parameters and publish
2692	per-compensator gain bundles (gain trajectories observable in log/trace/replay,
2693	dependency visible to the feedthrough graph, linearization holds unseeded gains
2694	constant).
2695	
2696	**Spec.** [§5.3][s5-3], [Appendix A][sA]
2697	
2698	**Rationale.** One-shot design-time gains = construction-time parameters or
2699	stopped-sim service outputs; commanded resets are same-tick inputs consumed in
2700	the *output stage* with `g` storing the matching `z⁺` ([Appendix A][sA] entry; reset
2701	honored only in `g` = one-tick-late outputs, legal where that is meant).
2702	
2703	**Rejected.**
2704	- *Writable parameter store / `Ref`-mutable component parameters:* invisible to
2705	  log, trace, replay and the feedthrough graph — [D-031][d-031]'s raw-poke rejection
2706	  applied to parameters; breaks immutable component structs.
2707	- *A framework reset capability:* ordinary ports suffice — a second mechanism.
2708	- *Reset-in-`g`-only as the idiom:* publishes the stale command at the
2709	  engagement tick — the bump bumpless transfer removes; [§10.6][s10-6]'s `z⁻¹` discipline
2710	  makes the output stage the only same-tick path, [D-067][d-067].

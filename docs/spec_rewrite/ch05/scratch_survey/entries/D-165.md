5733	### D-165 — Split output-stage returns into public `y` and private `w`
5734	
5735	**Status.** superseded → [D-194][d-194]
5736	
5737	**Position.** Every output stage returns either `y::NamedTuple` (ports only) or
5738	`(y, w)::Tuple{NamedTuple, NamedTuple}`; a `nothing` in either slot is a probe
5739	error; an empty `y = (;)` is legal, so port-less stages fall out of the general
5740	law (stages are discovered by method existence, membership is a partition of
5741	declared ports that may be empty) — a stage producing neither ports nor `w` is
5742	a dead-stage build error (`DeadStage`).
5743	
5744	**Spec.** [§5.2][s5-2], [§5.4][s5-4], [§7.5][s7-5], [§11.2][s11-2], [§8.3][s8-3], [§9.5][s9-5], [§9.7][s9-7], [§13.2][s13-2], [§14.4][s14-4]
5745	
5746	**Rationale.** `w` carries the component's private intermediates: an
5747	`isbits`-leaf NamedTuple, never a table cell.
5748	
5749	**One-hop law**: `h_x`'s `w` flows to `h_xu` if defined, otherwise to the
5750	downstream set (`f`, guards, handlers); `h_xu`'s `w` flows to the downstream
5751	set; nothing flows implicitly — forwarding across hops is an explicit re-return
5752	(`(y, (; w..., extra))`). Symmetric on the discrete tier (`h_z` → `h_zu` →
5753	`g`), stated once.
5754	
5755	`w` joins the closed bundle name sets of `h_xu`, `f`, guards, handlers, `h_zu`,
5756	`g`; presence in a bundle follows the producing stage's probed return (bare-`y`
5757	producer ⇒ no `w` key ⇒ the [§13.2][s13-2] framing diagnostic on a consumer that
5758	destructures it).
5759	
5760	`w` is **SSA-passed inside fused executor passes** (the step fuses sweep + `f`;
5761	each event round fuses sweep + guards + fired handlers) and never persisted —
5762	freshness by construction, recomputation cost zero, and the executor commits to
5763	round-fusion as a design constraint.
5764	
5765	`w` types are probe-observed; the probe validates the NamedTuple form and
5766	consumer reads against the observed field set (did-you-mean from actual fields,
5767	weaker than declaration-backed but located).
5768	
5769	`w` joins the branch-shape rule and the **always-on check at the nominal
5770	activation**: expected = the nominal probe's observed type, one baked `isa`
5771	beside the `y` test — folds to zero instructions when stable, and converts the
5772	unintended-branch-divergence class (which otherwise surfaces only as
5773	allocations in testing) into a loud, located, field-naming error at first
5774	divergent execution, with blame text honestly citing the probe ("expected what
5775	the nominal probe observed"), complementing [§7.5][s7-5]'s canary (detection) with
5776	localization.
5777	
5778	**Non-nominal activations run no `w` check**: with no declaration for a
5779	branch-independent anchor and no store to embed into, a strict probe-observed
5780	check there false-positives on the legal constant-branch idiom
5781	(probe-branch-dependent expectations — the one-probe-point argument), while
5782	correctness needs no guard (a `Float64` in `w` under `Dual` is an honest
5783	zero-partial constant by the embedding guarantee; downstream promotion is
5784	exact).
5785	
5786	`local_types` is deleted with its satellites: stage membership derives over
5787	`output_types` alone; `ContractNameCollision` retired; `UndeclaredReturnField`
5788	candidates = `output_types`; `get_local` retired from the [§14.4][s14-4] selector family
5789	and [§11.2][s11-2]'s read bindings — the inspection path for intermediates is
5790	*promote to output* (FlightCore precedent: intermediates were only ever
5791	inspected by inclusion in the `Model` output); local cells leave the [§9.7][s9-7]
5792	store; [§8.3][s8-3] visibility becomes: declared in `output_types` = public, returned
5793	in `w` = private **by construction** (nothing to connect, list or filter);
5794	walkthrough 5 rewritten.
5795	
5796	Guidance, not law: a `w`-only `h_x` is redundant when `h_xu` exists (fold it in
5797	— both run once per sweep); it is the honest spelling of `u`-independent shared
5798	intermediates when no `h_xu` exists.
5799	
5800	**Rejected.**
5801	- *Walking the nominal-observed type to synthesize non-nominal expectations:*
5802	  rejected as machinery kept alive for a check that catches nothing the nominal
5803	  one misses.
5804	- *`local_types` status quo ([D-034][d-034]/[D-055][d-055]):* declaration + table cells +
5805	  presentational filtering for values that were never interface; threading is
5806	  structurally private and cheaper, and per-activation probe observation
5807	  dissolves the dropped-partials objection that rightly killed observation
5808	  authority for *pinned* locals.
5809	- *Pass-through on bare `y`:* the one implicit flow in the design, plus a
5810	  bare-`y`-vs-`(y, nothing)` subtlety needing a didactic paragraph.
5811	- *The `(y, nothing)` chain-terminate form:* no demonstrated customer; extra
5812	  fields downstream are harmless to a destructuring consumer.
5813	- *Opaque `isbits` `w`:* no name-shaped diagnostics.
5814	- *Persisted `w` slots / table cells for `w`:* a cell needs a fixed
5815	  per-activation type, and with `local_types` gone there are only bad sources —
5816	  probe-observed types detonate branch-dependently, the
5817	  `output_types`-inference flaw re-imported; a declaration resurrects what is
5818	  being deleted; an anchor+walk keeps the output-side walk alive for private
5819	  values. SSA-passing dissolves the question: a flowing value has no type
5820	  contract to violate, promotion handles mixed branches exactly — this is what
5821	  makes probe-observation sound here where [D-034][d-034]/[D-055][d-055] rightly rejected it for
5822	  cells. Also: staleness class, store traffic for register-resident values, `w`
5823	  names re-entering the cell namespace, and the loss of "every cell is a
5824	  connectable port". The forfeited snapshot visibility is covered by
5825	  promote-to-output, with a debug-mode SSA capture recorded as the cell-free
5826	  door.
5827	- *Restricting port-less stages to `h_xu`:* the one-hop law routes a sole
5828	  `h_x`'s `w` directly downstream; with no `h_xu` defined, port-less `h_x` is
5829	  the spelling whose no-`u` view set honestly declares the intermediates
5830	  `u`-independent.

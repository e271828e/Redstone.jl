2593	### D-086 — Compile the executor's schedule into unrolled statically-typed entries
2594	
2595	**Status.** ratified
2596	
2597	**Position.** The compiled executor ([§9.7][s9-7]): schedule data compiled per
2598	activation into a concretely-typed entry tuple over statically typed storage,
2599	walked by compile-time unrolling — [§7.5][s7-5]/[§9.5][s9-5]/[§5.1][s5-1] are reachable only under
2600	full specialization.
2601	
2602	**Spec.** [§5.1][s5-1], [§7.5][s7-5], [§9.5][s9-5], [§9.7][s9-7]
2603	
2604	**Rationale.** Phase bodies as the semantically forced outer decomposition
2605	(order-free `h_x`/`f`/`g` blocks, topo-ordered `h_xu` block, event callables —
2606	seams cost nothing; parallel-evaluation and incremental-recompile doors
2607	recorded); chunking behind statically-typed function barriers bounds compile
2608	cost (superlinear → linear, measured; chunk size the only representation
2609	freedom); mitigation ladder = lazy activations, reduced opt-level for
2610	non-nominal activations, precompile-workload caching (TTFX a CI artifact);
2611	views rebuild-per-call (hoisting = compiler CSE, whose legality condition is
2612	the staleness rule); schedule tuples constructed type-opaquely, consumed only
2613	by the walk.
2614	
2615	Annotation (2026-10-02): amended by [D-289][d-289]. [D-289][d-289] restates the compile-cost
2616	figures and the mitigation ladder, and the ladder drops the reduced
2617	optimizer level for non-nominal activations. The rejection of type-erased
2618	call tables stands, now measured.

2620	**Rejected.**
2621	- *Vector-of-abstract entries:* per-entry dynamic dispatch boxes stage returns
2622	  — kills [§7.5][s7-5] and its canary role, unfolds [§9.5][s9-5]'s check; union splitting
2623	  rescues only toy scale and cannot close an open method set.
2624	- *Type-erased call tables (`FunctionWrapper`-style):* same specialization
2625	  count as chunk-of-one with extra machinery, no cross-entry inlining/SROA,
2626	  a relied-on seam on internal ABI — the [D-017][d-017] lesson.
2627	- *Framework-maintained view hoisting:* manual cache-invalidation duty for
2628	  loads the compiler hoists exactly where legal; mis-scoping = silent
2629	  stale-state reads.

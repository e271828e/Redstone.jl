676	### D-018 — Tier-2 event localization via dense output and bracketed root-finding
677	
678	**Status.** ratified
679	
680	**Position.** Tier-2 localization: lazy cubic Hermite dense output + bracketed
681	derivative-free root-finding (ITP/Brent) on guard probes that run the sweep;
682	post-event interpolant invalidation + remainder step + bounded event budget
683	whose exhaustion *degrades* — localization off for the rest of the frame,
684	further crossings firing at Tier-1 granularity in the next boundary's
685	iteration, with a chattering warning; trajectory-determined, never wall-clock
686	([D-080][d-080] intact), and never a `StepError`; probes evaluate the raw interpolated
687	state (off-manifold like RK stages), projection running at the `t*` boundary
688	where [§10.6][s10-6]'s edge checks read it — a projection that undoes the crossing costs
689	one extra harmless boundary.
690	
691	**Spec.** [§10.4][s10-4], [§10.6][s10-6]
692	
693	**Rationale.** Recorded only through the rejections below.
694	
695	**Rejected.**
696	- *Per-probe projection:* projection cost inside the root-finder loop, for
697	  interpolant drift far below localization tolerance.
698	- *Newton/AD localization:* guards C⁰ not C¹ — kinks and σ′ = 0 stretches;
699	  discards the bracket certificate for local guarantees; negligible savings on
700	  rare microsecond probes.
701	- *Re-integration probes:* 4× cost; σ becomes trial-h-dependent.
702	- *Solver-matched high-order interpolants:* only matter above order 4.

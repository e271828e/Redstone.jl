393	### D-004 — Immutable value signals in a typed signal table
394	
395	**Status.** ratified
396	
397	**Position.** Immutable value signals in a typed signal table.
398	
399	**Spec.** [§4.1][s4-1]
400	
401	**Rationale.** Recorded only through the rejections below.
402	
403	**Rejected.**
404	- *Shared mutable buffers:* aliasing/staleness, concurrent-read hazards.
405	- *Mixed semantics:* second thing to document/test.
406	- *A monolithic per-component `y` struct:* freshness is per-struct, so it can
407	  be half-fresh mid-sweep with no way for a reader to tell — per-cell freshness
408	  is tied to the producer's schedule position.

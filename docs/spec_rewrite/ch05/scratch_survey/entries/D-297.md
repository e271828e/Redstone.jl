12524	### D-297 — Contracts by type, seeding not typing, one walk convention and declared publicity
12525	
12526	**Status.** ratified
12527	
12528	**Position.** Eight declaration-layer rulings that [§8.1][s8-1], [§8.2][s8-2], [§8.3][s8-3] and [§8.6][s8-6]
12529	state are fixed here.
12530	
12531	- A leaf's contract declarations are functions of the component's type,
12532	  type parameters included, never of its field values, because [§9.7][s9-7]'s entry
12533	  typing derives the bundle key set from the type. `ws_init` is exempt, being
12534	  by allocation. The rule is one authors keep, not a check the build can run.
12535	- Partials enter through per-invocation seeding, never through initialization
12536	  and never through typing.
12537	- Discrete producers pin wholesale, so a frozen discrete output is exact by
12538	  the typing rule. Declared `Float64` initial values embed as zero-partial
12539	  constants.
12540	- The criterion, not uniformity, is the rule: a `T` belongs in a signature
12541	  exactly where the declaration's non-nominal behavior is underdetermined by
12542	  its nominal restriction.
12543	- Every declaration is read with one walk rule. A `Float64` written at a
12544	  participating leaf walks, and a pin is written on the page as `Pinned`.
12545	- A store puts its letter in the bundle only when it is non-empty.
12546	- "Every `Float64` position follows the scalar" reads the declaration as
12547	  written, so a concretely typed field is frozen without appearing in the
12548	  contract.
12549	- Publicity is never implicit. A leaf's port and an assembly's face are
12550	  public only by declaration.
12551

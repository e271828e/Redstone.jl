8997	### D-239 — Report a typo'd return field alone, without the unproduced port
8998	
8999	**Status.** ratified
9000	
9001	**Position.** A stage returning a field `output_types` does not declare is
9002	reported by the port check's `UndeclaredReturnField` alone.
9003	`DeclaredNotProduced` belongs to the completeness pass over the complete
9004	products, which runs only once every port check has passed.
9005	
9006	**Spec.** [§8.3][s8-3], [§8.4][s8-4], [§13.1][s13-1], [Appendix C][sC]
9007	
9008	**Rationale.** [§8.4][s8-4]'s fifth walkthrough promised the pair: the did-you-mean
9009	and the unproduced-port error with the product lists in hand. The port check
9010	runs inside the probe chain, which consumes each product as it goes, so a
9011	failed check aborts the chain under [D-229][d-229] and the completeness pass never
9012	reaches the model; the 2026-09-04 conformance audit recorded the single
9013	diagnostic. Delivering the pair means recomputing the unproduced set at the
9014	throw site, where it is knowable only once the component's other stage has
9015	run: at stage 2, or at stage 1 on a component with no `output_direct`. And
9016	the second diagnostic carries nothing the first does not: renaming the field
9017	produces the port, and the next build is clean. [D-057][d-057]'s no-suppression rule
9018	is untouched. It keeps a diagnostic two passes both produce, as the
9019	typo'd-wire pair of [§13.1][s13-1], and never asks a pass to manufacture one after the
9020	chain has stopped.
9021	
9022	**Rejected.**
9023	- *Pair at the throw site:* a second copy of the completeness check with
9024	  weaker information, silent exactly when a stage 2 exists, so the promise
9025	  would hold except sometimes.
9026	- *Collect the port check to the stratum barrier:* a component with an
9027	  unproduced port has no cell for it, so every downstream probe needs a skip
9028	  arm or a synthesized stand-in — the sentinel machinery [D-229][d-229] rejects.

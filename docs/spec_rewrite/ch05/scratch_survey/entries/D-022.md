798	### D-022 — Periphery architecture: no shared mutable model
799	
800	**Status.** ratified
801	
802	**Position.** Periphery architecture: no shared mutable model — staged inputs
803	drained at frame top + immutable snapshot published per boundary; every handoff
804	one atomic reference op, GC as reclamation; no user code or unbounded work in
805	framework critical sections; control on a separate atomic surface (staging
806	cannot un-pause a drainless loop); interactive = batch + devices.
807	
808	**Spec.** [§11.1][s11-1]
809	
810	**Rationale.** Recorded only through the rejections below.
811	
812	**Rejected.**
813	- *Transplanted `io_lock`:* loop budget hostage to arbitrary code under the
814	  lock; input timing scheduler-determined and unrecorded — replay undefinable
815	  in principle; protects a live-mutation idiom the immutable table removed.
816	- *Full message-passing periphery:* per-device typed channels — same design
817	  with heavier ceremony.

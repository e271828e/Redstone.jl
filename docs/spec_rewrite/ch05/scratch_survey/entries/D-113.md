3430	### D-113 — Close four kindless diagnostic rules with new payload fields
3431	
3432	**Status.** ratified
3433	
3434	**Position.** The kind audit closes four kindless rules and makes one sketch
3435	honest:
3436	
3437	- `UnknownPort` is widened with a wire-end discriminator —
3438	  `source`/`destination`, that end's path and port list — a typo'd source port
3439	  being the same walkthrough-1 mistake read at the other end.
3440	- `DeploymentInvalid`: deployment parameter, value in hand, violated constraint;
3441	  service batch per [D-057][d-057]'s declarative class, sibling of `StopFaceInvalid` at
3442	  the `Simulation`-construction site.
3443	- `TrimProblemInvalid`: offending problem field, shapes/names in hand; service
3444	  batch, mirroring `SurfaceResolution` — the residual/tolerance length case
3445	  joins when improvement #7's `tolerances` field is adjudicated in the authoring
3446	  cluster (discharged, [D-118][d-118]).
3447	- `ConditionNodeMisuse` for [§14.2][s14-2]'s mixed-`merge` error method: offending
3448	  argument type, node kinds in hand; raised at composition time before any
3449	  resolution pass runs or any origin exists — hence its own kind, not a
3450	  `ConditionResolution` sub-kind.
3451	- `faces` enforces `except`/`only` mutual exclusivity with a
3452	  `declaration_error`, and `UnknownFaceSelection` gains a reason field (unknown
3453	  names / both selectors given).
3454	
3455	**Spec.** [§6.1][s6-1], [§8.4][s8-4], [§8.8][s8-8], [§9.2][s9-2], [§14.2][s14-2], [§14.8][s14-8], [Appendix C][sC]

3457	**Rationale.** Recorded only through the rejections below.
3458	
3459	**Rejected.**
3460	- *`UnknownSourcePort` as a second kind:* the two ends are one mistake; an
3461	  `end` payload field tests exactly as precisely without doubling the taxonomy.
3462	- *Folding the merge rejection into `ConditionResolution` sub-kinds:* misstates
3463	  the site — no origin exists at merge time.
3464	- *Dropping the sketch's mutually-exclusive comment instead of enforcing it:*
3465	  silent-ignore of a passed argument is the warn-but-continue pattern the spec
3466	  rejects everywhere else.
3467	- *A dedicated kind for the both-selectors case:* same site, severity and
3468	  audience as `UnknownFaceSelection` — a reason field suffices.

2712	### D-090 — Return handler updates as bundle-law NamedTuples
2713	
2714	**Status.** ratified
2715	
2716	**Position.** Handler returns are NamedTuples under the bundle law ([§5.2][s5-2],
2717	[§9.5][s9-5]): `(; x, m)`, a key present iff the store exists AND the handler updates
2718	it — a pure FSM returns `(; m = …)`, a reset map `(; x = …)`.
2719	
2720	**Spec.** [§5.2][s5-2], [§9.5][s9-5]
2721	
2722	**Rationale.** Checks per key: `x` present ⇒ complete against the state field
2723	set, `m` present ⇒ names-subset, unknown key ⇒ did-you-mean against `{x, m}`
2724	narrowed to the declared stores — the argument-side `FieldError` machinery run
2725	in both directions.
2726	
2727	**Rejected.**
2728	- *Positional pair `(x⁺, m⁺)`:* reintroduces the padding [D-074][d-074] bans on
2729	  arguments — `((;), m⁺)` / `(x⁺, (;))` for single-store components — and lets
2730	  the two stores swap with a diff-shaped rather than name-shaped error.

2212	### D-074 — Hand off component-function arguments as one named bundle
2213	
2214	**Status.** ratified
2215	
2216	**Position.** Named-bundle hand-off: every component function is `fn(comp,
2217	args)` — one NamedTuple bundle of zero-copy views, destructured by name in the
2218	signature; `project(comp, x)` alone stays positional.
2219	
2220	**Spec.** [§5.2][s5-2], [§7.3][s7-3], [§11.4][s11-4]
2221	
2222	**Rationale.** The bundle law (a field exists iff the store or tier fact
2223	exists: undeclared stores absent, never `nothing`-filled; `t` everywhere, `Δt`
2224	discrete-only, `ws` iff `workspace` declared); closed per-function-kind name
2225	sets, growth = a decision-log event; probe failures carry did-you-mean against
2226	the legal set, synthesized from a `FieldError` (structured: type + field as
2227	data, Julia ≥ 1.12) matched against the bundle's own NamedTuple type — no
2228	message-text scraping, the bundle staying a bare NamedTuple, a getproperty
2229	wrapper the recorded fallback.
2230	
2231	**Rejected.**
2232	- *Positional signatures + a clock-view type:* dead slots written unread,
2233	  un-droppable mid-list holes; the view type subsumed by naming.
2234	- *Keyword arguments via `Base.kwarg_decl` reflection:* a relied-on seam on an
2235	  internal binding — the [D-017][d-017] `task_local_storage` lesson.
2236	- *Keyword + `_...` slurp:* permanent noise; "signature = read-set" weakens to
2237	  "at least".
2238	- *One context object carrying workspace too:* grab-bag accretion; mutable
2239	  member muddies the immutable-views teaching.
2240	- *Time as a wired `Clock` component:* time is ambient in `f`/output
2241	  stages/guards/handlers — two access idioms for one quantity.
2242	- *`nothing`/`(;)` padding for undeclared stores:* defers the error from
2243	  destructuring to first field access, with a worse message.
2244	- *A `comp.Δt` virtual property:* [D-019][d-019] — the period is a schedule-position
2245	  fact, and `===`-identical siblings may sit under different `rates` keys.
2246	- *Positional signatures, additionally:* leave the `t`/`Δt` scalar pair
2247	  swappable without any error, both being bare same-typed reals.

7144	### D-196 — Rename the phase-body sweeps to stage-numbered names
7145	
7146	**Status.** ratified
7147	
7148	**Position.** The phase-body roster's sweep blocks rename `sweep_hx` →
7149	`sweep_1` and `sweep_hxu` → `sweep_2`; arities, entry sets and the roster's
7150	other members (`rhs`, `ticks`) are untouched.
7151	
7152	**Spec.** [§9.7][s9-7], [Appendix B][sB], [Appendix D][sD]
7153	
7154	**Rationale.** Post-[D-195][d-195] the `hx`/`hxu` spellings read as
7155	continuous-tier-only, but each sweep is a genuinely tier-mixed body — one
7156	block whose entries mix `h_x`/`h_s`, the other `h_xu`/`h_su`. The stage number
7157	is the tier-neutral fact ([§5.3][s5-3]), so the names state it.
7158	
7159	**Rejected.**
7160	- *Keeping the fused spellings:* quietly re-fuses the letter [D-195][d-195] split, in
7161	  the one place a reader meets both tiers inside a single compiled block.
7162	- *Per-tier sweep pairs (`sweep_hx` + `sweep_hs`):* would split the execution
7163	  structure to serve a name — the single topologically-ordered body per stage
7164	  is the design.

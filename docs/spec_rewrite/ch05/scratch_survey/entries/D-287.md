12080	### D-287 — Handler-return keys, struct-valued port embedding and the branchless payload
12081	
12082	**Status.** ratified
12083	
12084	**Position.** The always-on check reads handler returns by key, embeds a
12085	struct-valued port by its constructor, and reports no branch.
12086	
12087	- A handler return's key set is checked first. An unknown key, or one
12088	  naming a store the component does not declare, is a build error with
12089	  did-you-mean against `{x, m}` narrowed to the declared stores.
12090	- A present `x` is complete against the state field set.
12091	- A struct-valued port's embedding uses the standard cross-eltype
12092	  constructor, and a missing one fails loudly with both types named.
12093	- The conformance failure payload omits the source branch.
12094	
12095	**Spec.** [§5.2][s5-2], [§9.5][s9-5]
12096	
12097	**Rationale.** Checks per key: `x` present ⇒ complete against the state
12098	field set, `m` present ⇒ names-subset, unknown key ⇒ did-you-mean against
12099	`{x, m}` narrowed to the declared stores — the argument-side `FieldError`
12100	machinery run in both directions (as recorded in [D-090][d-090]). [§9.5][s9-5] states the key
12101	set's place first.
12102	
12103	The constructor rule has no prior entry; [§9.5][s9-5] states it.
12104	
12105	A value does not say which branch produced it, and the diff and replay
12106	suffice (as recorded in [D-053][d-053]).
12107	
12108	**Rejected.**
12109	- *Positional pair `(x⁺, m⁺)`:* reintroduces the padding [D-074][d-074] bans on
12110	  arguments — `((;), m⁺)` / `(x⁺, (;))` for single-store components — and
12111	  lets the two stores swap with a diff-shaped rather than name-shaped error.
12112	  (As recorded in [D-090][d-090].)
12113	- *Branch identification in the error:* a value does not say which branch
12114	  produced it — the diff + replay suffice. (As recorded in [D-053][d-053].)
12115	- *None recorded for the constructor rule.*

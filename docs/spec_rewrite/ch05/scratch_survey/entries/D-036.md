1158	### D-036 — Table mechanics: stage returns are NamedTuples of port values
1159	
1160	**Status.** ratified
1161	
1162	**Position.** Table mechanics: stage returns are NamedTuples of port values;
1163	aggregate `y` = virtual merge, gathered per call, never stored; custom structs
1164	are port values — one port, one cell, atomic in wiring; granularity guideline:
1165	bundle what shares a stage and is consumed together.
1166	
1167	**Spec.** [§4.3][s4-3]
1168	
1169	**Rationale.** Recorded only through the rejections below.
1170	
1171	**Rejected.**
1172	- *Bare-struct returns with field-splatting:* ambiguous, type-lossy merge,
1173	  reflection-hungry. "Type-lossy" spelled out: neither the struct type nor the
1174	  methods that justify its existence can be reassembled from a flat merged
1175	  namespace.
1176	- *Sub-field wiring:* the port stops being the atomic unit; field-projection
1177	  connector kept as guarded addition.
1178	- *Per-field cells for struct internals:* nested display is a lazy view, not
1179	  storage.

5365	### D-153 — Add re-arm tracking to complete the once-per-event rule
5366	
5367	**Status.** ratified
5368	
5369	**Position.** **The event phase's per-event loop state is named and normative —
5370	the prior ([D-082][d-082]), a `fired` flag (the once-per-event rule's register), and a
5371	within-boundary `re-arm` flag**, set when a round observes the event fired and
5372	its guard not-holding; `EventDeferred` emits (at most once per event per
5373	boundary) when a round observes fired ∧ re-armed ∧ holding — the genuine
5374	intra-boundary falling-then-rising edge, never the blessed sticky case
5375	(fired-and-keeps-holding warns nothing).
5376	
5377	**Spec.** [§10.6][s10-6], [§11.7][s11-7], [§11.8][s11-8], [Appendix C][sC]
5378	
5379	**Rationale.** A round-5 kernel dry-run finding (finding 9), completing [D-082][d-082]'s
5380	prior rule. **A deferred event's quiescence prior is recorded not-holding**
5381	(the intra-boundary re-arm edge survives the boundary), so it genuinely fires
5382	at the next boundary — under the bare prior rule the quiescent holding sample
5383	would swallow the edge and the promised "waits one step" would never resolve.
5384	All three registers are detection bookkeeping in loop state — not `z`, not
5385	captured, reset by warm restart ([D-082][d-082]'s doctrine extended); cost budgeted
5386	explicitly: two `Bool`s per event beyond the prior.
5387	
5388	Annotation (2026-10-02): amended by [D-181][d-181] and [D-292][d-292]. The `fired` and
5389	`re-arm` flags and `EventDeferred` are retired; the registers are the prior,
5390	the last-observed sample and the firing count. That they are named and normative
5391	stands.
5392	
5393	**Rejected.**
5394	- *The warn-on-holding-after-fired rule:* the only one implementable from the
5395	  spec's stated registers — false-positives on every sticky flag, a
5396	  per-boundary warning stream consuming the 16-entry ring [§11.8][s11-8] budgets for real
5397	  diagnostics — the anti-diagnostic pattern [§11.7][s11-7] names.
5398	- *Dropping `EventDeferred`:* silent deferral, against the
5399	  flag-the-granularity-cost doctrine the once-per-event rule was adopted with.
5400	- *Prior = final quiescent sample unconditionally:* [D-082][d-082] as written — swallows
5401	  the re-arm edge, so the deferral never resolves and "waits one step" is
5402	  false.

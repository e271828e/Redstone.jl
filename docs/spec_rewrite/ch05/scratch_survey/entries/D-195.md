7088	### D-195 — Give the discrete state its own letter `s`
7089	
7090	**Status.** ratified
7091	
7092	**Position.** The discrete state un-fuses from `x` into its own letter `s`;
7093	[D-173][d-173]'s `z` retirement stands untouched — bare `z` still means only the shift
7094	operator `z⁻¹`.
7095	
7096	- The discrete-tier names re-split: `h_x`/`h_xu` → `h_s`/`h_su`, `init_x` →
7097	  `init_s`, `y_x` → `y_s`, bundle field `x` → `s`, `x⁺ = g(x,u,t)` → `s⁺ =
7098	  g(s,u,t)`; the continuous tier keeps the `x` family, and `f`/`g`, `m` and
7099	  `Δt` keep their meanings.
7100	- The per-function-per-tier closed bundle-name sets become per-function closed
7101	  sets again: the two tiers' name families are disjoint by construction.
7102	- The wrong-letter error class [D-173][d-173] retired rejoins
7103	  `DeclarationOnWrongTier`'s member set — a discrete leaf declaring `h_x`, or
7104	  a continuous one declaring `h_s`, is statically diagnosable again.
7105	
7106	**Spec.** [§3.2][s3-2], [§5.2][s5-2], [§5.3][s5-3], [§7.3][s7-3], [§8.2][s8-2], [§8.7][s8-7], [§9.3][s9-3], [§9.5][s9-5], [§12.5][s12-5], [§13.7][s13-7], [§14.1][s14-1], [§3.4][s3-4], [§8.6][s8-6],
7107	[Appendix A][sA], [Appendix B][sB], [Appendix C][sC], [Appendix D][sD] (all companions swept)
7108	
7109	**Rationale.** [D-173][d-173] correctly retired `z` but recycled the continuous letter,
7110	erasing a real distinction: the discrete state is a different object — no
7111	derivative, any isbits type (pinned, eltype-generic or mixed), latched between
7112	ticks, stored in per-component state stores where the continuous state lives in
7113	the flat buffer ([§9.4][s9-4]) — and one letter made leaf declarations and framework
7114	prose read as one mechanism where the engine holds two.
7115	
7116	[D-173][d-173]'s "every candidate letter is taken" premise has since emptied for `s`:
7117	the Laplace variable appears nowhere in the spec — the document's only
7118	transform-domain symbol is `z⁻¹` — and `s` carries unique positive precedent,
7119	being legacy FlightCore's own discrete state field (`Model.s`), which [§12.5][s12-5]'s
7120	consumer survey already quotes as `x`/`s`; the migration (`migration_outline.md`) reads the legacy
7121	vocabulary back rather than introducing a third letter. The "doubled API"
7122	objection is nominal, not per-leaf: a leaf is strictly one tier ([D-056][d-056]) and
7123	still implements exactly one name family, and the doubling buys back the
7124	wrong-letter diagnostic. The hybrid-systems `x⁺` convention [D-173][d-173] leaned on
7125	models a single state that both flows and jumps; the framework's tiers are
7126	disjoint ([D-056][d-056], [§3.2][s3-2]), so its premise never applied here. [D-173][d-173]'s
7127	`is_discrete` rejection is untouched — the arity-is-the-tier doctrine survives
7128	with the letters split.
7129	
7130	**Rejected.**
7131	- *`w`:* free in current text since [D-194][d-194], but permanently means intermediates
7132	  in the log's lineage ([D-165][d-165], [D-169][d-169], [D-194][d-194]) — reuse would make one letter
7133	  mean two things across the log's history; reads as process noise/disturbance
7134	  in the state-space literature; prefix near-miss with the `ws` workspace
7135	  field.
7136	- *`d`:* `D` is already the compiled sample-rate divisor ([§8.7][s8-7], [Appendix D][sD]) and
7137	  the feedthrough matrix in `linearize`'s return, `d` the trim decision vector
7138	  ([§14.7][s14-7]); differential-operator reading, flagged by [D-173][d-173] already.
7139	- *Keeping the fusion:* the collision argument that motivated it was against
7140	  `z`, not for `x` — with a clean letter available, the shared letter's only
7141	  remaining yield is the halved name count, which per-tier disjointness makes a
7142	  diagnostic asset instead.

9929	### D-257 — Each artifact renders itself
9930	
9931	**Status.** ratified
9932	
9933	**Position.** The build-side and deployment artifacts print through `show`
9934	methods, with no accessors.
9935	
9936	- `show(::Structure)` prints the anchor table with the `A₀` row and the
9937	  component table with the rate-scope rows. `show(::Dataflow)` prints the
9938	  execution order with port classes. `show(::Schedule)` prints the rows and
9939	  the hyperperiod chart. `show(::Build)` and `show(::Deployment)` print a
9940	  summary and their parts. (Amended 2026-09-21, ahead of increment 48:
9941	  `Events` renders itself too, each component's event names with their
9942	  policies, and it is among the parts `show(::Build)` prints. Extended
9943	  2026-09-22, with increment 48b: `show(::Build)` also prints the feedthrough
9944	  edges the execution order was computed over, on a line of its own between
9945	  the outputs table and the events table, derived from the structure's
9946	  connections and the producers' stage-2 names, since [D-261][d-261]'s artifact rule
9947	  dropped the `edges` column.)
9948	- The chart guard is binary: the chart prints whole when `lcm(Dᵢ)` is at
9949	  most 100 base ticks, and otherwise the hyperperiod's length with "chart
9950	  omitted".
9951	- The face-route printer joins `Structure` when the routing chain is
9952	  recorded; that is `pending.md`'s "Smaller" bullet, unchanged. (Amended
9953	  2026-09-30: the printer is built. The structure step records each face's
9954	  routing chain at every level, `show(::Structure)` prints the root's routes
9955	  one line per chain, and the `pending.md` bullet is retired.)
9956	
9957	**Spec.** [§9.2][s9-2], [§13.7][s13-7]
9958	
9959	**Rationale.** [§9.2][s9-2] owes the anchor table, the component table and the
9960	hyperperiod chart, and [D-187][d-187] gave the chart a guard "against absurd
9961	hyperperiods" without saying what the guard does. With the artifacts typed
9962	([D-253][d-253], [D-254][d-254]), each table is one type's `show`, and a REPL user gets it by
9963	evaluating the value, which is what "printable" has meant since [D-049][d-049]. The
9964	guard is binary because one hyperperiod is the complete truth: the pattern
9965	repeats with period `lcm(Dᵢ)`, so a prefix is a sample that the chart's own
9966	argument says not to trust. A hundred base ticks is a screen.
9967	
9968	**Rejected.**
9969	- *Accessor functions returning tables:* a second API for what `show`
9970	  already is.
9971	- *Prefix rendering of a long hyperperiod:* a sample presented as a chart
9972	  whose claim is completeness.
9973	- *Superseded position — an unspecified guard ([D-187][d-187]):* the guard is now a
9974	  rule.
9975	
9976	
9977	Annotation (2026-10-07): the routing chain is no longer recorded.
9978	`show(::Structure)` derives each root face's route from the declared wires
9979	through `face_routes` ([D-315][d-315]); the printed form is unchanged.

4535	### D-139 — Give environment field handles a value-level constructor to prevent drift
4536	
4537	**Status.** ratified
4538	
4539	**Position.** Environment field handles get a **value-level constructor** — the
4540	map (component, input values) → handle exposed as a plain, pure, exported
4541	function (`atmospheric_field(atm; T_sl, p_sl, wind)` for the `SimpleAtmosphere`
4542	successor), with the component's swept output stage a **one-line call to it and
4543	never the reverse** — stated in [§4.4][s4-4] as a **shipped component's obligation**
4544	([Appendix A][sA] taught contract, [Appendix D][sD] entry), because only the component's
4545	author can write it: the real component composes sub-models, and anyone else
4546	reconstructing the map has re-created the silent-drift class [§5.3][s5-3] exists to
4547	kill.
4548	
4549	**Spec.** [§4.4][s4-4], [§5.3][s5-3], [§14.1][s14-1], [§14.2][s14-2], [§14.7][s14-7], [§14.9][s14-9], Appendices A/D
4550	
4551	**Rationale.** Bulk-data components owe only that the query math be *reachable*
4552	as a plain function; building a handle outside a build may then cost a resource
4553	load, acceptable because condition authoring is design-time code. [§14.1][s14-1]'s
4554	**caller-computable escape is extended to cover environment queries**: a
4555	condition needing one constructs the sweep's exact handle from the same values
4556	its `baseline` writes into the environment component's slots — or, in a rig
4557	where the handle *is* a root slot value, simply holds the value it wrote there
4558	— and calls the same query function the consuming component calls; one
4559	implementation of the field math evaluated one level up, no pre-sweep and no
4560	new mechanism. [§14.1][s14-1] also records the **environment-free fallback** through the
4561	existing second escape: promote the eliminated state coordinates to decision
4562	variables and enforce the targets as residuals on swept outputs, which needs no
4563	environment access at condition time at all (the detailed
4564	elimination-vs-enlargement material stays out of the spec — companion
4565	walkthrough, then `pending.md`). **Trim problems never author the environment** ([§14.7][s14-7],
4566	[§14.9][s14-9]): handles arrive through the user parameter record, the problem
4567	*receiving* the environment and never writing it, which is what keeps **one
4568	problem artifact valid across a full world and a thin rig** — a condition entry
4569	naming a wired input fails resolution by name, correctly ([§14.9][s14-9]), so a problem
4570	that wrote an environment face would apply only to rigs where that face happens
4571	to be unconnected. [§14.9][s14-9]'s "the aircraft is never literally the root" is
4572	**softened from doctrine to default**: leaving an environment face unconnected
4573	is legal by construction — the face becomes an ordinary root slot holding the
4574	handle *value*, written by the `baseline` like any other slot, the **test-rig
4575	idiom** and the function-valued sibling of a constant source — while
4576	`design_world(ac)` remains the shipped rig for design tasks, keeping the
4577	environment's tunables in the slot vocabulary that conditions, `capture`,
4578	linearization's input surface and the trace header already speak. [§9.6][s9-6]'s
4579	"`Kinematics.Initializer` … survives untouched, aircraft-side" is
4580	**corrected**: it survives aircraft-side with its `atmosphere::Model` argument
4581	respelled as a field handle (built at value level per [§4.4][s4-4], or held as a rig
4582	slot value). Recorded once, the orthogonal **2×2** the discussion established:
4583	*elimination vs. enlargement* (where target enforcement lives — closed-form in
4584	the condition math, or as residuals on swept outputs) × *component-produced vs.
4585	slot-held environment* (who owns the handle in the rig). Only the first axis
4586	decides whether a **second handle path exists at all**: under elimination the
4587	condition-side copy is **solution-defining** and must agree with the world's,
4588	whereas under enlargement a handle can at most inform the initial guess —
4589	convergence-relevant, solution-irrelevant. The second axis is a rig-shape
4590	choice and never touches trim doctrine. **Residual risk, mitigation deferred to
4591	`pending.md`** (landed as [D-262][d-262]): under elimination a params-vs-world handle mismatch
4592	converges to a *true* equilibrium at an *unintended operating point* — the
4593	eliminated targets are never residual-checked, so nothing complains — and a
4594	cheap post-commit read-back of EAS/γ/β against the requested targets catches
4595	the whole class.
4596	
4597	**Rejected.**
4598	- *Widening the condition signature to `condition(d, baseline)` so the math
4599	  reads the handle out of the baseline:* single-sources the handle in a rig,
4600	  but is **rig-only** — in a full world the environment face is wired and
4601	  absent from the baseline, and serving it there would mean pre-sweeping the
4602	  environment subtree; it also makes every problem's meaning depend on the
4603	  baseline it is applied against — the hidden-input shape [§14.1][s14-1]'s overlay-base
4604	  decision kills, reintroduced one level up — and it breaks the pure condition
4605	  algebra that makes [§14.9][s14-9]'s `at`-lifting five lines.
4606	- *A pre-application or partial sweep making swept outputs readable at
4607	  condition time:* reaffirms [§14.2][s14-2]'s by-name rejection of init as a third
4608	  scheduled sweep, and deciding which subtree is state-independent and
4609	  therefore safe to pre-sweep is graph reasoning the services deliberately do
4610	  not do.
4611	- *Mandating enlargement as the sole route:* discards closed-form knowledge the
4612	  aircraft author has — the aero validity envelope is a box in (TAS, α, β) and
4613	  nothing like a box in Cartesian `v_eb_n`, so bounds either clip the feasible
4614	  set or admit excursions into table extrapolation, the practical source of
4615	  failed trims — where elimination keeps today's proven 7×7 shape.
4616	- *Reading the environment through `reads`:* circular — reads are gathered
4617	  after the sweep the condition precedes.
4618	- *Duplicating the atmosphere's `h_xu` in aircraft trim code:* the drift class
4619	  itself.
4620	
4621	Stated to forestall the reading: none of this reopens [D-008][d-008]'s rejected resource
4622	injection — no registry, no invisible composition, just a plain function call
4623	on values the caller already holds.
